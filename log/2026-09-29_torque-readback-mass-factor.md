# 2026-09-29 力矩读回含粒子质量的校准系数：之前的功率数都偏大约 22%

## 发现经过

用户问：粘度修正后流速为什么没有下降。为了定量回答，计算了 30 s 时刻流场的各项耗散，
过程中发现求解器里流体的总质量是 36.0 kg，而 29.6 L 水应为 29.5 kg。原因是粒子质量取的是
ρ₀ 乘以"校准后的粒子体积"，而这个体积比一个格子的体积 dx³ 大。

## 原因

`utils/sph/case.py` 的 `_calibrate_particle_volume` 让规则晶格上不含自身的核函数求和等于 1：

```
V_p = 1 / Σ_{j≠i} W(r_ij)
```

邻居循环都跳过自身，少了 W(0) 这一项，所以 V_p 必须大于 dx³ 才能让求和等于 1：

| 维数，h/dx | V_p / dx^d |
| --- | --- |
| 3D，2.5 | 1.4380 |
| 3D，3（搅拌槽） | 1.2187 |
| 3D，4 | 1.0830 |
| 2D，5（方腔、Couette） | 1.1293 |

粒子质量 m = ρ₀ V_p（simulator_v1.py 上传 velocity_mass 时设定）。

- **加速度不受影响**：压力梯度、粘性项都经 KCG 矩阵归一化，V_p 的大小被抵消；流场与 V_p 无关。
- **力受影响**：`readback_rotor_torque()` 计算 Σ m_i (x_i − p) × (a_i − g)，结果正比于 m。
  粒子按间距 dx 排布，每个粒子实际代表的质量是 ρ₀ dx^d，所以读回的力和力矩是实际值的 V_p / dx^d 倍。
  也可以说：模拟的是一种密度为 1.2187 ρ₀ = 1216 kg/m³ 的流体，而功率数的分母用的是 998。

## 验证

### 1. 二维 Taylor–Couette 的稳态力矩（层流，有解析解）

内筒受到的力矩，单位深度：τ = 4π ρ ν Ω r_i² r_o² / (r_o² − r_i²) = 8.378×10⁻² N·m/m。
求解器的等效粘度是材料值的 0.910 倍（ξ = 0.01，由启动过程实测，`2026-09-28_kcg-xi-evaluation.md`）。

| 量 | 值 |
| --- | --- |
| 读回的力矩（36000–40000 步平均） | 8.669×10⁻² ± 4×10⁻⁵ |
| 读回 / 解析 | 1.035 |
| 预期，含质量系数：0.910 × 1.1293 | 1.028 |
| 预期，不含质量系数 | 0.910 |

实测与"含质量系数"的预期相差 0.7%，与"不含"的相差 14%。

### 2. 搅拌槽：角动量通量（只用速度场，不依赖读回的力）

定常时，桨对流体的力矩等于穿过包住桨的圆柱面的角动量净流出：
τ = ∮ ρ₀ (r u_θ) u_n dA。圆柱侧面、顶面、底面各取 6 mm 厚的薄层内的粒子求和，每个粒子的质量取 ρ₀ dx³。
圆柱半径取 60 和 66 mm，Rushton 的圆柱高 44 mm，PBT 的高 52 mm。都是 t = 30 s 的单个时刻。

| 算例 | Rushton：通量法 / 读回 (mN·m) | 比值 | PBT：通量法 / 读回 (mN·m) | 比值 |
| --- | --- | --- | --- | --- |
| 贴体一层，基准 | 35–37 / 46.3 | 1.29 | 14–15 / 19.7 | 1.36 |
| 贴体一层，ξ = 0.001 | 35–37 / 47.3 | 1.31 | 17 / 19.1 | 1.10 |
| 贴体一层，粘度修正 | 34–37 / 46.3 | 1.30 | 14 / 19.3 | 1.36 |
| 格点两层，裁剪 | 32–35 / 41.4 | 1.23 | 18–19 / 25.8 | 1.40 |
| 格点两层，不裁剪 | 35 / 40.5 | 1.15 | 22–23 / 28.2 | 1.24 |
| 三层加外皮，3 mm | 32 / 35.0 | 1.09 | 34–35 / 38.6 | 1.13 |

- 读回与通量法之比平均约 1.25，与"质量系数 1.2187 再加 TIC 造成的约 5%"（共 1.28）相符。
- 通量法是单个时刻的值，穿过圆柱面的净质量流量不为零（约为进出流量的 8–10%），所以它本身有约 10% 的不确定度。
- 通量法还显示：三层加外皮时 PBT 的角动量主要从侧面流出（径向排出 1.7 kg/s），叶片变薄后才变成从底面流出（向下泵送）。
  也就是说原来的厚叶片让 PBT 变成了径向流的桨。

### 3. 功率数随 h/dx 的变化

2026-09-26 平底槽的核半径序列，读回的总 Np 为 6.04、4.85、4.16（h/dx = 2.5、3、4），当时认为功率数对核半径非常敏感。
除以各自的质量系数后为 4.20、3.98、3.84，每档只差约 5%。原来 20% 的差别大部分来自质量系数。

### 4. 静水浮力测试（`_check_buoyancy_force.py`）

封闭方盒内静止的流体，中间放一个由转子粒子组成的方块（角速度为 0），开重力。方块受到的浮力应为 ρ₀ g N dx³。

| h/dx | 读回的力 / ρ₀ g N dx³ |
| --- | --- |
| 2.5 | 0.35 |
| 3 | 0.47 |
| 4 | 0.19 |

读回的浮力远小于理论值，而且随 h/dx 变化没有规律。原因是固体粒子的压力不是流体压力的延续（只由一步的密度增量决定，接近 0）：
对一个厚的固体，只有流体邻居贡献压力梯度，约为应有值的一半；方块边长 32 mm 只有核半径的 2–3 倍时还会更小。
这说明**对厚的固体、在有较大背景压力的情况下，读回的力不可靠**。搅拌槽里重力关闭，压力在 0 附近，叶片是薄片，情况不同：
通量法与读回之比稳定在 1.2–1.3。这个测试的结论是读回方法本身需要和合作者讨论。

## 对已有结论的影响

1. **所有已报告的功率数和力矩都要除以质量系数**（h/dx = 3 时为 1.2187）。涉及 2026-09-25 以来的全部 Np 日志、
   讨论文档和混合时间日志里的功率数。各日志里的原始数值不改，以本文件为准。
2. 之前"总 Np 与 M-Star、Fluent 一致"的说法不成立：更正后总力矩比 Fluent 低 29%，比 M-Star 低 21–25%。
3. PBT 在贴体单层叶片下与 Fluent 一致（高 4%）。Rushton 低 37%，是剩下的主要偏差。
4. 功率数对核半径的敏感性大部分是质量系数造成的假象。
5. 流场、流速、混合时间的结果不受影响：它们只取决于加速度。
6. 输入功率比 Fluent 低约 29%，流速却高 15%，能量耗散偏少的问题比之前估计的更突出。

## 需要合作者确认

- 粒子质量取 ρ₀ V_p 而不是 ρ₀ dx^d 是否有意；他计算受力时是否另有换算。
- 固体粒子的压力模型使厚固体上读回的力不可靠（浮力测试），力的正确算法是什么。
