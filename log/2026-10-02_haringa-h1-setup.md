# 2026-10-02 Haringa 2023 复现 H1 的准备：Rushton 槽生成器、流动统计、无剪切壁面选项，以及薄板挡板的密度漂移

分支 `test`。方案见 `docs/haringa2023_reproduction_design_2026-10-02.md`。

**结论先说：**

1. 新增标准 Rushton 槽的生成器（单桨槽和 54 m³ 双桨罐两个预设）、时间平均的流动统计（排出流剖面、泵送数、流型）和 H1 的分析脚本。
2. 新增求解器选项：材料标志 `free_slip: true` 的壁面不对流体施加黏性力（无剪切顶盖），默认关闭，关闭时与原代码相同（回归检查见下）。
3. 排查中发现：**薄板挡板会让静止流体的密度持续上升并加速**（本机 4 mm 单桨槽，10 到 25 kg/m³ 每秒），只要有背景压力。
   原因是板的虚粒子不参与密度扩散，板不像壁面那样把密度拉回 ρ0。是否失控取决于板的面积：板面积与壁面积之比 0.17（四块全宽挡板）失控，
   0.08（两块挡板，或四块半宽挡板）和 0.03（只有叶轮的板）不漂。30 L 槽全部薄板合计 0.16，静止时漂移但逐渐减慢（约 1 kg/m³ 每秒），处在边缘。
   H1 的挡板因此改为三层实心壁面粒子，静止 0.7 s 和旋转 1.8 s 内平均密度不变（变化 0.03 kg/m³ 以内）。
4. 另两条薄板的放置规则：板必须"替代"一层格点（板在格子平面上，平面上的格点删去）；壳层粒子恰好落在板平面上又在板轮廓之内时，
   它在板的哪一侧没有定义，静止槽里每块挡板有 ±0.3 N·m 的虚假力矩。生成器按这两条放置。
5. H1 的两个算例（3 mm 和 2 mm，各 60 s）已提交 Mahuika。

## 一、无剪切壁面（`free_slip`）

### 合作者原来的代码

固体粒子对流体的黏性力在 `force.comp` 里与流体之间相同（Morris 形式），壁面速度即固体粒子的速度，所以所有壁面都是无滑移：

    a_visc,i += 2(d+2) ν V_j (v_i − v_j)·x_ij / (r² + ε h²) ∇W̃_ij        对所有邻居 j，包括壁面

`MaterialParameters` 结构里有两个保留字段 `reserved_material_0/1`，未使用。

### 我们改成了什么

材料库里边界类材料可写 `free_slip: true`。保留字段 `reserved_material_0` 改名为 `free_slip`（结构布局不变，48 字节）。
任一材料设了这个标志时 spec 常量 93 `USE_FREE_SLIP_WALLS` 为真，否则邻居循环里多出的材料读取被编译去掉。

    流体 i 的邻居 j 是无剪切壁面粒子：只有压力项，没有黏性项（Adami 等 2012 的无滑移改无剪切的做法）
    反作用（solid_reaction_force）：无剪切壁面粒子从流体得到的也只有压力项
    薄板的虚粒子仍按 USE_THIN_PLATE_VISCOSITY

```glsl
// force.comp，流体的邻居循环
bool neighbor_free_slip = USE_FREE_SLIP_WALLS
    && material_parameters[material[neighbor_particle_id]].free_slip != 0u;
...
bool pair_has_viscosity = !neighbor_free_slip;
#if WITH_THIN_PLATES
if (neighbor_is_wall_dummy) pair_has_viscosity = USE_THIN_PLATE_VISCOSITY;
#endif
if (pair_has_viscosity) a_viscosity += ...;
```

连续方程、密度扩散、PST 都不变：壁面法向速度为零照旧，只有切向剪切去掉。

| 文件 | 改动 |
| --- | --- |
| `experiment/v1/shaders/common.glsl` | 结构字段 `free_slip`；spec 93 `USE_FREE_SLIP_WALLS` |
| `experiment/v1/shaders/force.comp` | 邻居循环和固体反作用里按标志去掉黏性项 |
| `utils/sph/case.py` | `MaterialEntry.free_slip`；材料库读 `free_slip`，只允许 `kind: boundary`；spec 映射 93 |
| `experiment/v1/utils/simulator_v1.py` | spec 项 93；材料表上传 `free_slip` |

### 验证

`experiment/v1/checks/_check_free_slip_lid.py`：同一单桨槽（4 mm）分别用无滑移和无剪切顶盖跑，平均顶盖、壁面、挡板、叶轮的轴向力矩。

| 算例 | 时段 | 叶轮 | 顶盖 | 说明 |
| --- | --- | --- | --- | --- |
| 薄板挡板（后来发现不稳定，见第三节），无滑移 | 0.8 到 1.2 s | −114.8 | −40.2 | 顶部有明显的虚假旋流 |
| 同上，无剪切 | 0.8 到 1.2 s | −109.0 | +0.56 | 顶盖力矩降到 1.4%，剩下的是离散压力对的水平分量 |
| 实心挡板，无滑移 | 1.2 到 2.0 s | −130.6 | +0.19 | 有挡板时顶部几乎没有旋流 |
| 实心挡板，无剪切 | 1.2 到 2.0 s | −131.8 | +0.11 | |

力矩单位 mN·m，已除以 1.2187。有旋流时黏性剪切确实被去掉；正式设置下顶盖条件对力矩的影响在千分之二以内。

**回归**：改动前（提交 aac4fe5，临时目录编译）和改动后的代码跑同一个 30 L 槽（4 mm，薄板，p_b 2000，4000 步）：
第 500 步力矩 −0.107856 对 −0.107935 N·m（差 0.07%，逐次运行的非确定性水平），2000 到 4000 步平均 −0.1063 对 −0.1053（差 1%，瞬时起伏之内），
速度 78.3 对 78.4 步/s，粒子数相同。

## 三、薄板挡板的密度漂移

H1 的第一版生成器用薄板挡板。叶轮转起来约 1 s 后全槽密度上升到发散。为把几何和流动分开，改用静止的槽（`--rpm 0`，转子不动）逐项排查。
本机 4 mm，背景压力 4611 Pa（2 ρ U_tip²），c₀ 30.4 m/s，表中是全槽流体平均密度（ρ0 = 1000）：

| 变体 | 0.12 s | 0.36 s | 0.47 s | 趋势 |
| --- | --- | --- | --- | --- |
| 没有薄板（只有轴） | | 1000.0 附近，最小最大 999.3 到 1001.2 | | 不漂 |
| 只有叶轮薄板 | | 999.1 到 1001.6 | | 不漂 |
| 只有挡板薄板，在格子平面上 | 1001.8 | 1006.5 | 1009.9 | 加速上升 |
| 同上，挡板转到任意角度 7.5° | 1001.3 | 1006.3 | 1009.6 | 加速上升 |
| 同上，挡板离壁 5.6 mm、离底 4 mm | 1000.8 | 1004.6 | 1007.6 | 上升 |
| 同上，用 30 L 槽的格子和壁面约定 | 1001.9 | 1008.4 | 1013.1 | 加速上升 |
| 同上，用 30 L 槽的 c₀ 20.6 m/s 和 p_b 2000 Pa | 1001.6（0.18 s） | 1006.5（0.53 s） | 1009.7（0.70 s） | 上升 |
| 同上，背景压力 0 | 1000.000 | 1000.000 | 1000.000 | 完全静止，速度为 0 |
| 只有两块挡板薄板（面积减半） | 1000.36 | 1000.44 | 1000.42（0.71 s） | 不漂 |
| 四块半宽挡板薄板（面积减半） | 1000.29 | 1000.30 | 1000.28（0.71 s） | 不漂 |
| 挡板夹在两层流体之间（格子三向错开半格） | 1002.2 | 1008.1（0.30 s） | | 更快；全部薄板加旋转时约 1.1 s 发散 |
| **三层实心挡板加叶轮薄板** | 1000.30 | 1000.30 | 1000.32（0.71 s） | 不漂；旋转 1.8 s 也在 1000.29 到 1000.32 |
| 对照：30 L 槽（ρ0 = 998），全部薄板 | 999.55（0.18 s） | 999.96（0.35 s） | 1000.52（0.70 s） | 上升但减慢 |

机理（板旁的流体，按挡板平面统计）：流体有持续的法向速度（如 −0.02 到 −0.08 m/s，背离板），PST 位移每步把粒子推回同样的距离，
两者在位置上相抵，但连续方程不含位移项，于是密度一直累积。驱动来自背景压力：均匀压力下 ∑ V ∇W 在板附近不为零，力正比于压力，
p_b = 0 时一切不动。壁面附近同样的误差被密度扩散吸收（壁面粒子在扩散项里按 ρ0 计，把流体密度拉回），薄板的虚粒子不参与密度扩散，没有这个锚。
是否失控由板面积决定（两侧板面合计，与壁面积之比）：

| 情况 | 面积比 | 静止时的平均密度 |
| --- | --- | --- |
| 单桨槽，只有叶轮的板 | 0.03 | 不漂 |
| 单桨槽，两块挡板或四块半宽挡板 | 0.08 | 不漂，稳定在比初值高 0.3 到 0.4 处 |
| 30 L 槽，全部薄板（挡板 0.12） | 0.16 | 漂移，逐渐减慢 |
| 单桨槽，四块挡板 | 0.17 | 加速上升 |
| 54 m³ 罐，四块挡板（若用薄板） | 0.21 | 预计失控 |

误差源与板面积成正比，壁面的纠正能力与壁面积成正比；密度升高使压力升高，又放大误差源，超过一定面积后形成正反馈。
叶轮的板面积小，所以叶片和圆盘可以继续用薄板。

另外两条，生成器已遵守：

- **板必须替代一层格点**：修正矩阵和核函数和把板粒子当邻居，力和连续方程把它们当壁面虚粒子。板在格子平面上、平面上的格点删去时，
  板加流体是一套规则点阵。板夹在两层之间等于多出一层粒子（上表倒数第三行）。
- **壳层粒子不能恰好落在板平面上又在板轮廓之内**：它在板哪一侧没有定义。第一版把挡板轮廓延伸进侧壁、底板和顶盖壳层，而 90°、180°、270°
  的法向量有 10⁻¹⁷ 的舍入残差，静止槽里三块挡板各有 −0.3 N·m、壁面 +0.9 N·m 的虚假力矩（0° 那块为零）。现在挡板实心，不再有这个问题；
  生成器另把挡板坐标架的舍入残差清零。

30 L 槽的已有结果不受影响：它的挡板在任意角度，不在格子平面上，静止漂移慢且减速，生产算例 30 s 的密度在 984 到 1007 之间。

## 有什么影响

- 求解器：只有 `free_slip` 一个新选项，默认关闭，关闭时编译结果与原来等价（回归见上）。
- 单桨槽的挡板厚 3 dx（2 mm 时 6 mm），与原文"3D 内件"的 5 mm 接近；叶片和圆盘仍是薄板。叶轮薄板在静止流体里也有约 1 m/s 的局部虚假速度
  （已知的"近壁扰动"，30 L 槽的 PBT 叶片处同样），叶尖附近的 k 会因此偏高。
- 54 m³ 罐在 25 mm 间距下三层挡板厚 75 mm，偏厚，H2、H3 开工前要定（设计文档第 6 节）。

## 需要合作者确认

1. 无剪切壁面只去掉黏性项、连续方程照旧，这个做法他是否认可。
2. 薄板的密度漂移：是否让虚粒子在密度扩散项里按 ρ0 计（与壁面相同），或者他有别的办法。这影响所有用薄板挡板的算例，包括 30 L 槽。
3. 板替代格点层的规则，以及板平面上壳层粒子的侧别问题，他是否在别的算例里遇到过。
