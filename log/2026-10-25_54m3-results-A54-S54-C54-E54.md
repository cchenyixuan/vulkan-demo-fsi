## 4. 拆分：逐细胞状态 vs 底物场反馈

沿 C54、E54 的 lifeline（120 到 320 s，C_s 每 0.1 s）离线积分九池，两边都用细胞自己的旋钮因子（`_integrate_ninepool_lifelines.py --ki 49.2 --ki-reference-gly 24.6 --freeze-e11 --step 0.05`，初值恒化器稳态、X_gly 15.5，统计取起点后 10 s 起）。两边的差只来自底物场，这就是"局部双向对单向（逐细胞离线积分）"。

| 量 | 离线 on C54 场 | 离线 on E54 场 | 场的差 | GPU C/E（含逐细胞层） |
|---|---|---|---|---|
| X_gly 均值 / p5 / p50 / p95 | 15.70 / 3.29 / 16.14 / 26.93 | 15.01 / 3.05 / 15.34 / 26.07 | +4.6 / +7.8 / +5.2 / +3.3 % | +1.0 % / ×2.7 / +4.6 / −9.2 % |
| μ 均值 / p50 / p95 | 0.0287 / 0.0280 / 0.0622 | 0.0267 / 0.0256 / 0.0595 | +7.5 / +9.4 / +4.5 % | −0.8 / +8.2 / −11.8 % |

离线 on C54 场复现 GPU 的 C54 池（均值 15.70 对 15.48，μ 0.0287 对 0.0287），积分器一致。

读法：

1. 群体平均双向作为细胞模型（全罐一个状态）在饥饿尾部严重失真：X_gly p5 差 2.7 倍，30 L 只有 6 %。尾部差随循环时间（3 s 对 21 s）放大，这是"局部性随罐体增大"的直接证据。
2. 但这一项几乎全是逐细胞状态的作用：每个细胞按自己的饱度吃。单向协议如果逐细胞离线积分（Haringa 的做法），也能拿回来：同一场上 p5 3.05，对局部双向 3.29。
3. 真正属于底物场反馈的部分：整个分布上移 3 到 8 %，μ 均值 +7.5 %。但两份场的平均 C_s 本身差 8.5 %，30 L 的同协议重复显示 C_s 的实现噪声就有 7 到 16 %，所以这 3 到 8 % 目前分不清是反馈还是实现噪声。需要 54 m³ 的同协议重复（C54 再跑一次，Mahuika 约 52 h）才能定。
4. 两层在 μ 均值上恰好相抵：场 +7.5 %，逐细胞层 −7.5 %（E54 场上逐细胞对群体平均），所以 GPU 的 C/E 均值只差 0.8 %。
