# 2026-10-09 lifeline 拼接（Haringa 2018 的 80 h 序列）与青霉素合成能力的损失

## 原来的代码

离线积分器 `_integrate_ninepool_lifelines.py` 只沿记录的 lifeline（60 到 200 s）积分池。小时级的池（E11、v33 即 q_p）在这么短的记录里不动。Haringa 2018 的做法：胞外环境统计定态，把不同 parcel 的 lifeline 随机首尾相接拼成 80 h 序列再积分，看 q_p 对波动的适应。

## 改成了什么

`--stitch-hours H [--stitch-count N] [--stitch-segment S] [--stitch-seed] [--stitch-report]`：N 个合成细胞，每个细胞反复随机抽一条记录的 lifeline（S = 0 时整段，否则随机起点的 S 秒）接到自己的序列后面，池在线积分，不落盘 9.6M 条记录；每 `--stitch-report` 小时报告 X_gly、μ、q_p、E11、X_sto、ATP 的均值和 p5/p50/p95，最终每个细胞的状态存 npz。`--step 0.03`（等于记录间隔）足够。

参照细胞：同一模型在恒定 C_s 下积分，C_s 取"平均饱和度相等"的值 C_ref = K_s q̄/(1 − q̄)，q̄ 是记录上 C_s/(C_s + K_s) 的平均。用算术平均 C_s 会因为羽流样本把参照喂得太饱（Monod 饱和项的 Jensen 效应，参照 μ 0.085 对群体 0.025）。这个参照在前 30 h 有意义，更长时间后它自己也漂（恒定 C_s 不是恒化器，E11 衰减时没有 C_s 升高来补偿），所以终态比较改用 0 维恒化器的稳态（见下）。

## 结果：30 L，3 mm，55 g/kg，连续进料 2.0e-4 mol/s（D1 的 lifeline，30 到 90 s 窗口）

2500 个细胞 × 80 h，单向 D1one3b 和两向 D1two3 的 lifeline 各一次，登录节点各约 4.5 h。

| 合成时间 | 单向 lifeline：q_p / μ / E11 | 两向 lifeline：q_p / μ / E11 | 恒定 C_ref 参照的 q_p | 相对参照 |
|---|---|---|---|---|
| 20 h | 4.159e-4 / 0.0254 / 0.1210 | 4.191e-4 / 0.0266 / 0.1213 | 4.276e-4 | −2.7 % / −2.3 % |
| 40 h | 4.038e-4 / 0.0251 / 0.1150 | 4.081e-4 / 0.0263 / 0.1152 | 4.149e-4 | −2.7 % / −2.4 % |
| 60 h | 3.962e-4 / 0.0251 / 0.1108 | 4.008e-4 / 0.0245 / 0.1111 | 4.027e-4 | −1.6 % |
| 80 h | 3.909e-4 / 0.0246 / 0.1079 | 待补 | 3.915e-4（参照已漂到 μ 0.021） | −0.2 % |

0 维恒化器稳态（`_model_ninepool.run`，Cs_f 0.0895）作为理想混合参照：D = 0.02 时 μ 0.0250（含 v_d 0.005）、q_p 4.034e-4、X_gly 15.2、E11 0.1028。群体 80 h 时 μ 0.0246、X_gly 15.0 与之相当，q_p 3.909e-4 比它低 **3.1 %**，E11 0.108 还在向 0.103 下降，q_p 也还在降（v33 的时间常数约 70 h），稳态下的损失估计 5 到 6 %。已另起 300 h、1000 细胞的拼接来取稳态值。

单向和两向 lifeline 拼接出的 q_p 差 0.4 到 0.8 个百分点，与 D1 的结论一致。

## 判断

Haringa 2018 在 54 m³ 报 q_p 损失 18 到 50 %；30 L、工业细胞密度下只有 3 到 6 %。这是"实验室罐波动小、损失小"的低端点，和图 2、4 的尺度对比同一口径。54 m³ 的拼接用同一命令对 A54 的 lifeline 做即可。
