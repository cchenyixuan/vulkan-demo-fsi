# 2026-09-30 流体之间成对力的对称修正（spec 48）

分支 `test`。新增开关 `numerics.symmetric_pair_correction`，默认关闭，关闭时与原来的代码完全一致。

## 背景

角动量收支（`log/2026-09-29_angular-momentum-budget.md`）发现：全场为正压时，流体与流体之间的成对力给流体一个净力矩，
方向与旋转相反。重力 0.3 倍时它拿走转子输入的 37%，重力 1 倍时拿走 92%。真实流体内部的力是成对反作用的，这一项应当为零。

## 合作者原来的代码

`force.comp` 里压力项和粘性项都用粒子 i 自己的 KCG 矩阵修正核梯度：

```glsl
vec3 kernel_gradient_corrected = self_correction_matrix * kernel_gradient_raw;   // M_i^-1 grad W_ij
a_pressure -= neighbor_volume_dynamic * pressure_combined / self_density * kernel_gradient_corrected;
a_viscous  += morris_coefficient * viscosity_uniform * neighbor_volume_dynamic * dot(...) / (...) * kernel_gradient_corrected;
```

对应的公式（压力为正时的对称形式）：

    a_i = − Σ_j V_j (P_i + P_j) / ρ_i · M_i⁻¹ ∇W_ij

j 对 i 的力用 M_i⁻¹，i 对 j 的力用 M_j⁻¹。两个力之和不为零：

    F_ij + F_ji = − m V (P_i + P_j) / ρ · (M_i⁻¹ − M_j⁻¹) ∇W_ij

这个净力与**绝对压力**成正比，与相邻两个粒子的矩阵之差（粒子排列的不均匀程度）成正比。

这是文献里常见的做法：用自身的矩阵保证梯度一阶精确，代价是不严格守恒。不是代码错误。

## 我们改成了什么

打开开关后，**流体与流体**的粒子对用两个矩阵的平均：

    ∇W̃_ij = ½ (M_i⁻¹ + M_j⁻¹) ∇W_ij

```glsl
vec3  kernel_gradient_pair = kernel_gradient_corrected;
float pair_volume_viscous  = neighbor_volume_dynamic;
if (USE_SYMMETRIC_PAIR_CORRECTION && USE_KCG_CORRECTION && self_params.kind == MATERIAL_FLUID) {
    vec4 neighbor_matrix_a = correction_inverse[neighbor_particle_id * 2u];
    vec4 neighbor_matrix_b = correction_inverse[neighbor_particle_id * 2u + 1u];
    if (neighbor_matrix_b.w > 0.5) {                       // 邻居也是流体
        mat3 neighbor_correction_matrix = mat3(...);
        kernel_gradient_pair = 0.5 * (kernel_gradient_corrected + neighbor_correction_matrix * kernel_gradient_raw);
        pair_volume_viscous  = 2.0 * self_mass / (self_density + neighbor_density);
    }
}
```

- 压力项和粘性项改用 `kernel_gradient_pair`。
- 粘性项的邻居体积改用 2m / (ρ_i + ρ_j)，对 i 和 j 相同。
- 交换 i 和 j 时 ∇W_ij 变号，其余因子不变，所以两个力大小相等、方向相反，线动量严格守恒。
- 力的方向不一定沿两个粒子的连线，所以角动量不是严格守恒，只是误差大幅减小。

没有改的部分：

- 流体与固体的粒子对仍用 M_i⁻¹。
- 密度方程、涡量、位移修正、标量输运仍用 M_i⁻¹。
- 负压区的 TIC 形式 (P_j − P_i) 没有改。它本身不是成对反作用的力，但不含绝对压力。

### 结论

1. 流体之间成对力的角动量误差基本消除：重力 1 倍时从转子输入的 92% 降到 0.2%。
2. 角动量现在由壁面和挡板拿走：重力 1 倍时壁面一项从 2.7 升到 59.7 mN·m。
3. 压力水平不再压低流动：原来重力 1 倍的动能比 0.3 倍低 31%，现在两者接近，重力 1 倍略高。
4. 转子力矩上升 4%（重力 0.3 倍）和 9%（重力 1 倍）。事先估计力矩会下降，这个估计是错的。
5. 6 s 时流动还在建立（dL/dt 仍为正），稳态的力矩和速度需要 30 s 的算例。

### 没有解释的地方

- 重力 0.3 倍时成对力一项是 +4.6 到 +6.5 mN·m（流体得到角动量），重力 1 倍时接近零。原因没有查。
  可能的来源：力的方向不沿连线；少数负压粒子对走 TIC 形式。
- 位移修正拿走的角动量从 4.3–4.6 升到 5.3–6.1 mN·m。
- 这两个算例用的是旧几何。新几何（挡板 24 mm 加钟形罩）下的结果还没有算。

## 为什么原来的验证没有暴露这个问题

仓库里合作者的验证算例是二维和三维的顶盖驱动方腔，重力都是零，也没有背景压力。

- 误差与绝对压力成正比。方腔里压力有正有负，平均接近零，量级是 ρU² 的十分之几。
  负压区走 TIC 形式，不含绝对压力。
- 我们的搅拌槽不加正压时也是这样：全槽平均压力约 5 Pa。
- 加了重力或背景压力后，全槽平均压力是 670–2200 Pa，而主体区的动压 ρu² 只有约 20 Pa，两者相差两个量级。
  这是我们新加的工况，超出了原来验证过的范围。
- 方腔的验证指标是中线上的速度剖面。顶盖持续驱动，流动被四面壁面约束，没有检查力矩或角动量收支。
- 方腔的分辨率很高（二维 100 万粒子），粒子排列整齐，相邻粒子的矩阵之差小。

提交记录里有一条"drop dam_break case"（2026-05-05）。溃坝算例有重力，删除的原因不清楚。

## 需要合作者确认

1. 用自身矩阵修正核梯度是否是有意的选择（精度优先），是否测试过有重力的算例。
2. 对称的平均矩阵是否可以接受。它让流体粒子的压力梯度不再严格一阶精确。
3. 有没有更好的守恒形式的建议，例如只在压力项里对绝对压力的部分做对称处理。
4. 溃坝算例被删除的原因。
