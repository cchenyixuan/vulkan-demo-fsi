# 2026-10-28 state_limited 的离线积分器，以及单向协议在 P54 上的结果

## 原来的代码

只有 Tang 9-pool 的离线积分器（`experiment/v1/checks/_integrate_ninepool_lifelines.py`）。state_limited 的细胞只能在 GPU 上随双向算例一起算，无法得到"文献单向协议"下的细胞响应：在一个场上沿 lifeline 离线积分细胞模型，细胞不反馈到 C_s。

## 改成了什么

新增 `experiment/v1/checks/_integrate_state_limited_lifelines.py`。公式与 `predict.comp` REACTION_MODE 2 逐行对应（每克生物量）：

    供给 q_sup = q_max C_s / (K_s + C_s)
    需求 q_dem = (μ_d + α μ_max) / Y + m_s，μ_max = Y (q_max − m_s)
    摄取 q = min(q_sup, q_dem)；维持 min(q, m_s)；μ_act = Y (q − 维持)
    状态 μ ← (μ + r μ_act) / (1 + r)，r = dt/τ，μ_act > μ 时 τ = τ_up，否则 τ_down

- μ_d：`--demand-state own`（细胞自己的 μ，单向协议的评估方式，默认）或 `recorded-mean`（每个记录时刻 lifeline 上记录的 growth_rate 的平均，复现 `state_coupling: mean` 的 GPU 算例，用于验证）。
- C_s 在记录之间线性插值，隐式欧拉步长 ≤ `--step`（0.01 s）。GPU 对供给做了一步内的隐式线性化（dt ~1e-4 s，修正量 1e-4 量级），单向细胞不消耗 C_s，这里用连续形式。
- `--init-from-record`、`--check`（与记录的 growth_rate 比较）、`--statistics-start`（默认 120 s；积分总从第一个记录开始）、`--record-stride`（抽样检验）、`--biomass`（只用于把记录的累计 uptake 换成 q）。
- 输出 npz：time、uid、growth_rate、uptake、demand_limited（记录 × lifeline）。

## 验证（P54，2 万条 lifeline，统计 120 到 240 s）

| 检验 | μ 均值 离线 / GPU（1/h） | 逐点差 rms / max（1/h） |
|---|---|---|
| V1：P54_own，own 状态，从记录起步 | 0.2518 / 0.2588（−2.7 %） | 0.0082 / 0.028 |
| V1，每 2 个记录取 1（0.2 s） | 0.2523（−2.5 %） | 0.0076 / 0.028 |
| V1，每 4 个记录取 1（0.4 s） | 0.2540（−1.9 %） | 0.0061 / 0.026 |
| V2：P54_mean，recorded-mean 状态 | 0.2496 / 0.2516（−0.8 %） | 0.0020 / 0.0054 |

离线积分对局部双向算例偏低约 2.7 %；加粗抽样反而略减小，原因未定（可能是 0.1 s 抽样漏掉的 C_s 短时峰与 min(供给, 需求) 的非线性相互作用）。比较不同场时用同一离线协议（离线对离线），这一偏差相互抵消。

## 单向协议的结果：own 状态的细胞在 P54_mean 的场上离线积分

P54_mean 的场就是"能力对齐的无状态摄取"场（摄取 = min(Monod 供给, 由 μ̄ 决定的全罐统一上限)，只依赖当地浓度），即文献单向做法的最佳版本。

| 量（120 到 240 s，所有记录与 lifeline） | GPU 局部双向（真值） | 离线，own 场 | 离线，mean 场（单向协议） | 单向对真值 |
|---|---|---|---|---|
| μ 均值（1/h） | 0.259 | 0.252 | 0.302 | +17 %（离线对离线 +20 %） |
| μ p5 / p50 / p95（1/h） | 0.073 / 0.239 / 0.515 | 0.071 / 0.232 / 0.500 | 0.096 / 0.278 / 0.592 | |
| μ < 0.1 1/h 的样本比例 | 11.2 % | 11.8 % | 5.8 % | 约一半 |
| 单条 lifeline 时间平均 μ：标准差 / p5 / p95（1/h） | 0.109 / 0.107 / 0.463 | 0.106 / 0.105 / 0.451 | 0.124 / 0.131 / 0.537 | |
| 细胞平均摄取 / 场的摄取 | | 0.970 | 1.186 | 物质衡算差 +19 % |

"场的摄取"为 lifeline 上记录的累计 uptake 在统计段的增量 ÷ 时长 ÷ x_bio（取 10 g/kg；实际 x_bio 在统计段约高 1.3 %，所以这个比值本身带约 −1.3 % 的偏差，V1 的 0.970 中包含它）。

读法：在群体平均场上，单个细胞各自适应，吃过糖的细胞能力升高，离线算出来比场允许的多吃约 19 % 的糖、平均生长快约 17 %，并把低 μ 细胞的比例低估一半。这些多吃的糖在场里并不存在：单向协议切断了细胞对 C_s 的反馈，结果在物质衡算上不自洽。局部双向中，这部分细胞会把当地的糖吃掉，别处的细胞因此更饿（饥饿时间分数 14.9 % 对 9.4 %，见 `log/2026-10-28_P54-results.md`）。

## 影响

- 新增检查脚本，不改求解器。
- 案例一的第三类指标（单向做法的物质衡算差额）有了第一个数：+19 %。

## 待确认

- 2.7 % 离线偏差的来源：需要一个以更密 lifeline 间隔（如 0.01 s）记录的短算例才能确认是抽样造成的。
- 30 L 的 P1 对（Paratera 上）可用同一脚本补算，作为 τ/τ_circ ≈ 1 的另一点。
