# 2026-10-08 D1 3 mm 结果：Tang 原模型下局部双向对单向，以及冻结场近似的代价

## 算例

30 L，3 mm 生产配置（136 万粒子，dt 6.56e-5 s），Tang 9-pool 无旋钮，x_bio 55 g/kg，初始池为生成器默认（0 维 μ ≈ 0.035 附近的稳态：gly 20、e11 0.131，C_s 7.4e-6），葡萄糖 2.0e-4 mol/s 从 20 s 起连续加入注入点，跑 90 s；20,000 条 lifeline 从 30 s 起每 0.03 s 记录，探针 0.1 s，快照 30、60、90 s。Paratera 5090：D1two3（局部双向）7.3 h，D1one3（单向，Monod 1354 μmol/g/h，K_s 9.8e-6）约 8 h。分析在登录节点上跑（`cluster_jobs/paratera/analyze_D1.sh`），本地副本 `output/D1_3mm/analysis`。

## 先说两处设置不一致

1. **单向容量与两向初始池不匹配。** 单向用的 1354 μmol/g/h 是 D = 0.05 稳态（e11 0.146）的 k_E11 X_E11，而两向池从生成器默认 e11 0.131 出发，两向容量只有 1214。单向的汇强了 11.5 %。这解释了底物场的差别：单向的 C_s 在所有分位数上都更低（均值 5.56e-5 对 5.79e-5，p50 2.4e-6 对 3.4e-6），饥饿区分数 20.0 % 对 12.6 %。生成器已改为单向容量默认按初始池推导（提交 94a3e8d）。
2. **lifeline 从 30 s 开始，进料从 20 s 开始。** 单向离线积分的进料前阶段只能沿探针平均 C_s 积分，但 20 到 30 s 的场已经不均匀（羽流），大多数细胞实际看到的是接近零的 C_s。结果 30 s 时双向细胞的 X_gly 均值 8.9、中位数 8.0，而离线积分给的初值是 17.5。这个初值差随时间消退：

| 窗口 | X_gly 两向 / 单向离线 | μ 两向 / 单向 | q = C_s/(C_s+K_s) 均值 两向 / 单向 |
|---|---|---|---|
| 30 到 40 s | 9.34 / 16.39 | 0.0093 / 0.0288 | 0.315 / 0.260 |
| 50 到 60 s | 12.43 / 15.48 | 0.0178 / 0.0264 | 0.325 / 0.329 |
| 70 到 80 s | 15.20 / 15.18 | 0.0256 / 0.0256 | 0.342 / 0.315 |
| 80 到 90 s | 15.15 / 14.42 | 0.0254 / 0.0234 | 0.352 / 0.306 |

到 70 s 以后两者的池统计一致到几个百分点，剩下的差别与第 1 条的汇强度差一致（单向 q 偏低）。

所以 D1 3 mm 这一对**还不能当作干净的验证**，需要补一个一致的单向：容量按池推导（1214），lifeline 从 t = 0 记录（离线积分从头跟每个细胞）。两向可以复用。

## 可以确定的结果

### 积分器在生产算例上通过检验

沿两向 lifeline 记录的 C_s 从记录的池出发离线积分，与 GPU 记录的池比：X_gly 最大差 8.9e-4（相对最大值）、μ 1.1e-3、q_p 4e-7、X_sto 1.2e-5。单向协议的离线部分没有问题，差别只来自 C_s 历史。

### 探针级的量一致

| 量 | 两向 | 单向 |
|---|---|---|
| 90 s 累计摄取（mol） | 1.4978e-2 | 1.4922e-2 |
| 90 s 平均 C_s | 5.59e-5 | 5.74e-5 |

准稳态下摄取等于进料，与汇的容量无关，差别体现在 C_s 的水平和分布上。

### 工业密度下 30 L 罐的异质性

55 g/kg、连续进料下 lifeline 的 X_gly 在 7 到 22（p5 到 p95）、μ 在 0.003 到 0.044 之间，饥饿区（q < 0.05）驻留 1.3 到 1.5 s、过量区 3.1 到 3.6 s。30 L 罐在这个密度下并非均匀环境，这是尺度对比的低端点数据。

### 冻结场近似（Haringa 2017、2018 的单向）在这里的代价

单向 lifeline 按 9、12、24 mm 分格求时间平均场，再沿同一轨迹取值：

| 格 | 空间（冻结场）方差占比 | 时间脉动占比 | 冻结场的饥饿分数 | 瞬态的饥饿分数 |
|---|---|---|---|---|
| 9 mm | 27.8 % | 72.2 % | 0.0 % | 18.5 % |
| 12 mm | 27.1 % | 72.9 % | 0.0 % | 18.5 % |
| 24 mm | 25.2 % | 74.8 % | 0.0 % | 18.5 % |

（区域阈值用 `regime_analysis` 的 Haringa 2023 定义：q < 0.05 饥饿，q > 0.95 过量。）瞬态 lifeline 上有 104k 次 SLS 饥饿事件（平均 6.4 s），冻结场版一次都没有：在这个罐、这个密度下，饥饿事件全部来自对平均场的时间脉动，冻结场把它们全部抹掉。结论对格大小不敏感。两向 lifeline 的同一分析（9 mm）：空间 28.5 %、时间 71.5 %，瞬态饥饿 11.4 %（SLS 62.8k 次，平均 9.5 s）对冻结场 0 %，与单向一致。

### 理想混合参照

`_compare_lifeline_cells.py` 里 q_p 对"同 μ 恒化器"的 +8 到 +9 % 没有意义：q_p 是小时级状态，90 s 内还是初值，而参照恒化器用的是 90 s 内被饥饿压低的 μ。这一项在 90 s 算例里不该报告。

## 补跑 D1one3b 之后的干净对比（2026-10-09）

D1one3b：3 mm 单向，容量按池自动推导 1214，lifeline 从 t = 0 记录（离线积分从头跟每个细胞，不再需要进料前阶段的均值近似），其余与 D1one3 相同。Paratera 5090 9.0 h。分析 `cluster_jobs/paratera/analyze_D1b.sh`，本地副本 `output/D1_3mm/analysis_b`。

| 量（30 到 90 s，2 万条 lifeline） | 局部双向 D1two3 | 单向 D1one3b |
|---|---|---|
| X_gly 均值 / p50 / p5 / p95 | 12.94 / 12.32 / 7.09 / 21.26 | 12.70 / 11.77 / 6.98 / 21.63 |
| μ 均值 / p50 | 0.0193 / 0.0169 | 0.0187 / 0.0154 |
| q_p、X_sto | 4.399e-4、2653 | 4.399e-4、2653 |
| 区域分数 E / L / S（0.2 / 0.05） | 0.578 / 0.296 / 0.126 | 0.556 / 0.297 / 0.147 |
| 驻留 E / L / S | 3.56 / 1.16 / 1.34 s | 3.41 / 1.17 / 1.49 s |
| C_s 均值 / p50 / p95 | 5.79e-5 / 3.42e-6 / 1.91e-4 | 6.32e-5 / 3.13e-6 / 2.28e-4 |
| 冻结场方差占比（9 / 12 / 24 mm） | 28.5 / 27.9 / 26.0 % | 28.2 / 27.6 / 25.6 % |
| 冻结场饥饿分数对瞬态（Haringa 2023 阈值） | 0 % 对 11.4 % | 0 % 对 13.4 % |

池统计一致到 2 到 3 %，区域分数差 2 个百分点，冻结场的两组数字几乎相同。C_s 的均值和 p95 差 9 到 19 %，但 p50 反过来，这是 60 s 窗口（两个混合时间）内羽流间歇性的实现差异，不是协议差异：同一协议重复两次也会有这个量级的离散（B1 的 C 对 E 在 200 s 窗口内 C_s 均值差 0.5 %，窗口更长、进料是单个脉冲）。要把这条差别压到噪声以下，需要更长的统计窗或重复算例；54 m³ 的 200 s 窗（3 个混合时间）会好一些。

结论：Tang 原模型下局部双向与单向在 lifeline 的池统计和区域统计上一致，图 3 可以用这一对。
