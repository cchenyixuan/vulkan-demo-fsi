# 2026-09-30 开重力时流体整体下沉的根源：壁面密度下限 ρ₀ 让顶盖托不住顶层流体

分支 `test`。接 `log/2026-09-30_tank-2mm-onset-diagnosis.md`（提交 c5022d6）。那份日志留下的问题是：
开重力并搅拌时为什么每一层都有向下的平均速度。本篇是排查过程和答案。

**结论先说：**

1. 根源是 `accumulate` 壁面模型里"固体密度不低于 ρ₀"这条下限（`density.comp`，合作者原来的代码）。
   顶盖处静水压为零，顶盖粒子要托住下面两层流体，压力必须能取静水压的负延拓；下限把它钉在 0，
   顶盖下两层的压力支撑第 0 步就差 12%。它们下沉，PST 位移把它们抬回去，动量却传给了整根水柱。
2. 去掉这条下限后（新开关 `numerics.solid_density_floor: false`，spec 常量 73，默认保持原行为），
   4 mm 搅拌槽 1 g 的下沉速度从 −0.39 降到 −0.02 × 10⁻³ dx/步，顶盖下第一层粒子数 2 s 内稳定在 93 到 95%
   （与不开重力时贴壁间隙的数值相同），第二层 100 到 101%。静止水柱同样。
3. 与搅拌无关：转子静止时漂移一样；PST 系数减半加倍、正则化 ξ、初始密度剖面、壁面初始密度都不改变它。
4. 副作用：去掉下限后全场 SPH 密度在启动 0.4 s 内降 0.3% 到 0.6%（压力低 1 到 2.5 kPa），之后稳定。与重力无关（0 g 时 −0.34%，1 g 转子静止 −0.58%）：
   `accumulate` 壁面（Crespo 的动态边界）启动时流体与壁面之间形成约 0.3 dx 的间隙，去掉下限后壁面粒子的密度随之下降，
   再通过扩散把流体密度带低；有下限时流体密度被壁面钉住，不记录这次膨胀。所以正式算例仍建议不开重力加背景压力；
   开重力的算例用这个开关时要配 p_b ≥ 3 kPa。
5. 顺带修了两处启动误差：静水压初始密度改为 Tait 流体的精确剖面（原来按 ρ₀g 积分，槽底压力梯度差 1%），
   `accumulate` 模式下壁面粒子也按静水压初始化（原来从 ρ₀、压力 0 起步，槽底流体第 0 步受 −335 m/s² 的吸力）。
   两处都只在开了 `hydrostatic_reference` 时起作用，不影响合作者的默认算例。

## 排查过程

全部在本机 4 mm 搅拌槽（0.46 M 流体粒子）上做，每个算例 0.6 到 2 s，1 到 4 分钟。
工具是 `experiment/v1/checks/_check_number_density_profile.py`（新增每层平均竖向速度位移、PST 位移、平均加速度三列）
和 `_analyse_offline_pressure_force.py`（用存盘的位置、密度、压力按 `force.comp` 的公式重算压力项）。

### 第一步：下沉是什么

1 g，转子转动，0.6 s 的存盘：

| 高度，mm | 平均 v_y，mm/s | 中位数 | 负值比例 | 平均 a_y + g，m/s² | 平均流速，m/s |
| --- | --- | --- | --- | --- | --- |
| 260–300 | −13.5 | −14.3 | 0.67 | 9.798 | 0.057 |
| 300–340 | −14.3 | −15.1 | 0.72 | 9.779 | 0.049 |
| 340–380 | −14.8 | −16.0 | 0.76 | 9.790 | 0.041 |
| 380–420 | −16.2 | −16.6 | 0.78 | 9.799 | 0.036 |

- PBT 以上的整块流体几乎静止（流速 0.04 m/s），却整体以 15 mm/s 下沉，平均值与中位数一致，与 r 无关：是均匀漂移，不是局部现象。
- 平均加速度 a_y + g ≈ 9.79，即净向下 0.02 m/s²，只有 g 的 0.2%。

离线重算压力项（y 300–400 mm，2000 个样本粒子），与求解器读回的加速度逐位一致（9.7855 对 9.7854）：

| 形式 | a_y，m/s² | 相对 g |
| --- | --- | --- |
| `reverse`，ξ = 0.01（求解器所用） | 9.7855 | −0.25% |
| `reverse`，ξ = 0 | 9.8667 | +0.58% |
| `own`，ξ = 0.01 | 9.9555 | +1.5% |
| 对称形式不修正 | 11.88 | +21% |

ξ = 0.01 让压力梯度小 0.83%。但 ξ = 0.001 的算例（压力项与 g 平衡到 0.03%）下沉速度一样，说明这个速度不是被力持续推出来的。

### 第二步：时间历史

每 25 步记录一次最初 600 步（转子静止）：向下速度从第 1 步起线性增长，0.05 s 时顶盖下已达 −0.53，
随后以约 0.1 s 周期衰减振荡，稳定在 −0.39。这期间各层平均加速度 9.4 到 9.7（差 1% 到 5%），顶盖下第 0 步为 8.66（差 12%），槽底层 9.18 到 9.29。

### 第三步：逐项排除

| 变体 | 顶盖下 v·dt，10⁻³ dx/步 | 判断 |
| --- | --- | --- |
| 基准 1 g | −0.39 | |
| 转子静止 | −0.38 | 与流动无关 |
| 启动斜坡 0.05 → 0.5 s | −0.37 | 与转子启动无关 |
| ξ 0.01 → 0.001 | −0.40 | 与正则化无关 |
| PST 系数 0.05 / 0.2 | −0.33 / −0.39 | 位移是响应不是驱动 |
| 壁面粒子按静水压初始化（第 0 步槽底 −335 → +9.2） | −0.38 | 与启动踢动无关 |
| 精确静水压剖面 + 壁面静水压 + ξ 0.001 | −0.37 | 三个启动误差全去掉也无关 |
| **去掉壁面密度下限** | **−0.02** | 根源 |
| 静止水柱（对照） | −0.21 → 去掉下限 −0.03 | 同一机理 |

### 机理

顶盖粒子在 `accumulate` 模式下密度不低于 ρ₀，压力不低于 p_b = 0。静水压参考点在顶盖，顶层流体压力接近 0；
它们的压力梯度估计需要上方邻居带静水压的负延拓（顶盖上 1 mm 处 −10 Pa，5 mm 处 −50 Pa），下限把这些值钉成 0，
顶盖下两层的向上支撑差 5% 到 12%。这两层下沉，把动量通过压力传给整根水柱；PST 位移把粒子抬回原处，
位置不变、密度不变（扩散抹平）、粘性看不见均匀速度，所以下沉速度保留下来，成为稳态。
顶盖处位移抬不足（0.38 对 0.39），顶层持续变稀；2 mm 时稀到一半就发散了。

| 文件 | 改动 |

| `experiment/v1/utils/simulator_v1.py` | spec 项；静水压初始密度改为精确剖面；`accumulate` 模式下壁面和转子粒子也按静水压初始化 |

| `experiment/v1/checks/_check_number_density_profile.py` | 新增每层 v·dt、位移、加速度列；存盘含加速度、位移、uid |
| `CLAUDE.md`、`experiment/v1/shaders/README.md` | spec 常量表 |

精确静水压剖面：dp/dd = ρ(p) g 与 p = B((ρ/ρ₀)^γ − 1) 联立得

    ρ(d) = ρ₀ (1 + (γ−1)/γ · ρ₀ g d / B)^(1/(γ−1))

原来的 ρ₀ (1 + ρ₀ g d / B)^(1/γ) 给出的压力是 ρ₀ g d，梯度比 ρ g 小 ρ/ρ₀ − 1，槽底 1%。

默认构建：spec 常量默认 true 时 `density.comp` 的分支与原来相同；1 g 基准算例 0.1 s 的各项数值与改动前一致（GPU 非确定性范围内）。

4 mm，1 g，转子转动，`solid_density_floor: false`，2 s：

| 时间，s | 顶盖下第二层 / 第一层粒子数 | 顶盖下 v·dt / 位移 | SPH 密度相对第 0 步 |
| --- | --- | --- | --- |
| 0.4 | 101.3% / 94.9% | −0.02 / +0.02 | 99.54% |
| 1.2 | 100.3% / 93.6% | −0.01 / +0.01 | 99.47% |

第一层的 93 到 95% 是贴壁间隙（不开重力时也是 94%），不再发展。

## 有什么影响

- 2 mm 发散的因果链闭合：壁面密度下限 → 顶层托不住 → 整柱下沉、PST 抬回 → 顶层变稀 → 2 mm 在 3 s 空洞、发散。
- 9 月 29 日以来开重力的算例（3 mm 对比、薄板对比、2 mm）都带着这个漂移；叶轮区受的影响小（粒子数 97%），顶部流场不可信。
- 去掉下限后 SPH 密度整体低 0.5%，来源未查（可能与贴壁间隙形成时壁面粒子密度随之下降有关）。
  开重力的正式算例要么等这个查清，要么配背景压力 p_b ≥ 2 kPa。不开重力加 p_b 的方案不受影响。
- PST 位移不进连续性方程这一缺陷仍在，它是漂移得以保留的条件之一，不是起因。

## 需要合作者确认

1. `accumulate` 模式的密度下限是为什么加的（防止壁面吸附流体？）。开重力的封闭槽必须去掉它或改成允许静水压的负延拓。
2. 去掉下限后 0.5% 的密度下降。
3. 静水压初始密度的精确剖面和壁面粒子的静水压初始化是否同意作为 `hydrostatic_reference` 的默认行为。
