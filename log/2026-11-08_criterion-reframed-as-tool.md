# 判据改为量化工具：不再主张可预测的判据

日期：2026-11-08。用户："如果没算 case 就能估计出来，那还要 cfd 干嘛呢"；"不再主张一个可预测的判据，对，我觉得这个角度更合理一些，我们提出一个量化工具就好"。

## 原来的思路

- `log/2026-11-07_relaxation-fraction-criterion.md`：I(τ) = I∞ · F(τ)，F 由单向 lifeline 离线积分得到，I∞ 为罐侧常数，目标是用单向信息预测何时需要双向耦合；再往前是 τ/τ_c、τ/τ95、τ/T_q 横轴（`2026-11-06_criterion-timescale-and-30L-repeats.md`）。
- 不改代码。

## 改成了什么

不再提出预测判据，改为一个量化局部效应的工具，三层：

1. **大小**：同一流场、同一模型下跑 own 与 mean（GPU 上成本相同），I(τ) = (S_own − S_mean)/(S_0 − S_mean)，以及绝对差 ΔS = S_own − S_mean。回答"这个罐、这个细胞模型，局部效应多大"。
2. **分解**：I = F(τ) · G(τ)。F = cov(μ_τ, s)/cov(μ_0, s)，细胞记忆保留的状态对比度，由单向 lifeline 离线积分得到；G = I/F，罐的反馈增益（细胞状态改变摄取、摄取改变浓度场与贫区边界），只能由双向模拟得到。原 I∞ 改称 G，因为它不是常数；τ → 0 时 own 即 Monod，I 与 F 都为 1，所以 G(0) = 1。
3. **用途换算**（在一个罐内）：ΔS(τ) 与容许误差 ε 比较得到 τ*，τ < τ* 时必须双向。

数据支持的结论：

| 编号 | 结论 | 依据 |
|---|---|---|
| C1 | 局部效应随 τ 下降；30 L 在 τ ≈ 20–30 s 消失，54 m³ 在 τ = 45 s 仍有 I = 0.17 | I：30 L 0.53 / 0.21 / −0.02；54 m³ 0.66 / 0.29 / 0.17 |
| C2 | 局部效应不是单一时间尺度比的函数 | τ_c、τ95、T_q 三种横轴都留下 0.15–0.30 的竖直差 |
| C3 | 单向信息在 30 L 够用、在 54 m³ 不够：G 在 30 L 为常数，在 54 m³ 随 τ 增大 | G：30 L 0.67 ± 0.09、0.68 ± 0.23；54 m³ 1.06 ± 0.06、1.77 ± 0.24、1.87 ± 0.44 |
| C4 | 局部效应改变的是群体异质性，不是平均生长 | 54 m³：own 与 mean 的 μ 均值差 ≤ 0.6 %，每条 lifeline 时均 μ 的离散度 own 是 mean 的 2.7–2.9 倍 |

不再主张：可由单向结果预测的阈值；两罐共用一条曲线；I∞ 为罐常数。
