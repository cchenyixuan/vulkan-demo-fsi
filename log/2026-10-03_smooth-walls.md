# 2026-10-03 光滑壁面：圆柱面和碟形底换成贴合曲面的粒子层（生成器选项 `--smooth-walls`）

分支 `test`。接 `log/2026-10-03_impeller-nearfield.md` 第十一节：在 Fluent 的流场里，我们 y < 25 mm 的槽底和下段圆柱面比 Fluent
多刹 5.4 mN·m（格子台阶上的压力形阻），槽底外圈的角动量在流型切换前就开始掉。用户：光滑壁面试一下。
问题：去掉台阶以后，Fluent 的流型能不能在我们这里维持住？

## 一、原来的代码

`utils/geometry/_demo_stirred_tank_30l.py`，`main()`：槽壳是液体区以外 `border` 层以内的全部格点。

    is_shell = ~is_fluid & ~is_rotor & ~is_wall_solid & ~in_blade & (sdf_interior > -0.5 * dx)
    is_shell &= sdf_interior <= shell + 0.5 * dx          # shell = border * dx
    wall = np.vstack([sites[is_wall_solid | is_shell], baffle_points])

流体格点要求 sdf ≤ −0.5 dx，槽壳格点 sdf > −0.5 dx，两者互补。平的顶盖与格子平行，没有台阶；圆柱面（r = 144 mm）
和碟形底（`FLOOR_PROFILE`）是台阶，台阶高度在 0 到 dx 之间变化。

## 二、改成了什么

新选项 `--smooth-walls`（默认关）。

### 1. `smooth_tank_shell(dx, layers)`：贴合曲面的槽壳

第 k 层（k = 0 .. layers − 1，layers = border = 3）在曲面外 (k + 0.5) dx，与平壁时格子壳第一层的位置相同：

- 圆柱面：半径 r_k = R + (k + 0.5) dx，R = 144 mm；每一圈 n = round(2π r_k / dx) 个粒子，相邻两圈错开半个间距；
  圈放在格子平面 y = j dx 上，从槽底边缘（y = −12 mm）以下 (layers + 0.5) dx 一直到顶盖壳的顶。

      for k in range(layers):
          radius = TANK_RADIUS + (k + 0.5) * dx
          count = int(round(2.0 * math.pi * radius / dx))
          ...angle = (np.arange(count) + 0.5 * (index % 2)) * (2.0 * math.pi / count)

- 碟形底：剖面 (r, y_floor(r)) 加密成 4001 点，切向 t = (dr, dy)/|·|，在约 dx 的弧长上滑动平均（剖面是折线，法向在折点处跳），
  外法向 n = (t_y, −t_r)（底部中心朝下，边缘的过渡圆角朝外下方）。第 k 层是偏移曲线

      Q_k(s) = P(s) + (k + 0.5) dx · n(s)

  按弧长每约 dx 取一点，每点绕轴成一圈（n = round(2π r / dx)，至少 3 个；r < 0.25 dx 时只在轴上放一个）。
- 槽底边缘的接缝：边缘以上的圆柱面优先，离它们不到 0.6 dx 的槽底粒子去掉；边缘以下的圆柱面粒子离剩下的槽底粒子不到 0.6 dx 的去掉，
  这样过渡圆角由槽底的层来贴合。

### 2. `main()` 里

    shell_points = smooth_tank_shell(dx, border)
    shell_points = shell_points[(wall_solid.signed_distance(shell_points) > 0.0)
                                & (rotor_region.signed_distance(shell_points) > 0.0)]
    is_shell &= (sites[:, 1] > LIQUID_HEIGHT - 0.5 * dx) & (radius_sites < TANK_RADIUS + 0.5 * dx)
    shell_points = shell_points[~points_closer_than(shell_points, sites[is_shell], 0.6 * dx)]
    （静止固体和流体格点里离 shell_points 不到 0.6 dx 的去掉）
    wall = np.vstack([sites[is_wall_solid | is_shell], baffle_points, shell_points])

- 格子槽壳只留顶盖（液面以上、r < R + 0.5 dx），而且整片保留；离顶盖格点不到 0.6 dx 的新槽壳粒子去掉。
- 落在格子固体里的新槽壳粒子（轴承座、穿过槽底的轴）去掉，那里还是格子固体。
- 其余格点（静止固体、流体）离新槽壳粒子不到 0.6 dx 的去掉：3 mm 时 83 个（挡板支架贴壁的部分），流体 0 个。

### 3. `points_closer_than(queries, others, distance)`

求每个查询点 `distance` 以内有没有 `others` 的点。网格单元边长取 `distance`，近邻只可能在周围 27 个单元里；
`others` 按单元号排序，用 `searchsorted` 找每个单元的区段。求解器环境没有 scipy，所以只用 numpy。

### 3. 结论

- 格子台阶形的槽底和下段圆柱面是我们的流型离开 Fluent 流型的触发因素：换成光滑槽壳，同样的初始场 10 s 内不再切换，
  Rushton 下方的环 0.30 N D³（Fluent 0.36，格子 1.59），主体轴向动能与 Fluent 相同。
- 台阶的害处不在总制动量（同样流场里 y < 25 mm 只比 Fluent 多 10%），在于制动放错了地方：挡板少出的 40% 由台阶在槽底补上，
  槽底旋流被刹掉，Rushton 下半段开始从下面抽水，形成正反馈。
- 光滑槽壳还不等于 Fluent：挡板制动少 40%、槽底摩擦少 65%，全槽旋流过强（角动量 +26%，主体周向动能 +34%）；
  下半叶道的平均 u_y 在零附近（Fluent −0.10）；两叶轮之间靠壁多一个小环。

## 六、小结与下一步

- 光滑槽壳（`--smooth-walls`）让 Fluent 的流型在我们这里维持住了：10 s 内不切换，Rushton 下方的环 0.30 N D³（Fluent 0.36），
  主体轴向动能与 Fluent 相同。以前所有 30 L 算例的槽底下环和主体动能偏高，主要是格子台阶造成的。
- 剩下的偏差是角动量收支：挡板在同样流场里只出 Fluent 的 60%，槽底的粘性摩擦只有 35%；全槽旋流过强。
  另外 3 mm 的 Rushton 力矩少 22%（2 mm 时正常）。
- 格子槽壳的圆柱面静止时就有约 −6 mN·m 的静态力矩（p_b 作用在挡板附近的台阶上，与挡板一类相互抵消），以前按类别拆的圆柱面值含这个偏差。
