# 2026-09-28 KCG 正则化 ξ 从 0.1 改为 0.01，删除反推函数，生成器增加 --skin 选项

## 决定

根据 `2026-09-28_kcg-xi-evaluation.md` 的评估，用户决定：ξ 改为 0.01，并删除 2026-09-27 为标量加的
`unregularized_correction_inverse()`。合作者对这一项的意见见讨论文档 5.2 节第 1 条。

## 改动

| 文件 | 内容 |
| --- | --- |
| 4 个入库算例的 case.yaml：二维方腔、三维方腔、Taylor–Couette、3 mm 搅拌槽 | `numerics.regularization.xi: 0.1` 改为 `0.01` |
| 4 个生成器：`_demo_cavity_case.py`、`_demo_cavity_case_3d.py`、`_demo_taylor_couette_2d.py`、`_demo_stirred_tank_30l.py` | 模板里的 xi 同样改为 0.01 |
| `experiment/v1/shaders/common.glsl` | `REGULARIZATION_XI` 的默认值改为 0.01（实际值始终由算例经特化常量给出） |
| `experiment/v1/shaders/helpers.glsl` | 删除 `unregularized_correction_inverse()` |
| `experiment/v1/shaders/density.comp` | SGS 的速度梯度直接乘存储的修正矩阵 |
| `experiment/v1/shaders/force.comp` | 标量位移修正的浓度梯度直接用存储的修正矩阵（这一项默认关闭） |
| `experiment/v1/checks/_check_scalar_box.py`、`_check_operator_consistency.py` | 默认的 xi 改为 0.01 |
| `utils/geometry/_demo_stirred_tank_30l.py` | 新选项 `--skin`，默认 0.5，行为与原来相同；为下一个提交的单层叶片测试准备 |

没有改动的：correction.comp 仍然在加 ξ 之前把 d / tr M 存进 correction_inverse[2i+1].z，标量扩散项仍用它归一化。
它不增加任何读取，并且让扩散算子的精度与 ξ 无关。

代码对比（density.comp）：

```diff
     if (USE_SCALAR_SGS && self_is_fluid) {
         if (USE_KCG_CORRECTION) {
-            velocity_gradient = velocity_gradient
-                              * unregularized_correction_inverse(self_correction_matrix);
+            velocity_gradient = velocity_gradient * self_correction_matrix;
         }
```

## 影响

ξ = 0.01 时，存储的逆比精确的逆小 0.8%（3D，h/dx = 3）或 0.9%（2D，h/dx = 5），原来是 7.6% 和 8.1%。
所有用修正梯度的项都相应增大约 7%：压力梯度、Morris 粘性项、δ 密度扩散、PST 位移、涡量诊断。

| 量 | ξ = 0.1 | ξ = 0.01 |
| --- | --- | --- |
| 压力梯度与精确值之比，3D | 0.924 | 0.992 |
| 二维 Couette 实测等效粘度 / ν | 0.843 | 0.910 |
| 三维晶格上 Morris 粘性项与精确值之比 | 0.783 | 0.841 |

**之前的结果不能与新结果严格比较。** 二维方腔的等效雷诺数从约 1.19 倍标称值变为约 1.10 倍。
搅拌槽在启动 3 s 内的功率数和平均速度没有变化（7.80 对 7.81），长时间的结果要重跑才知道。

## 验证

| 检查 | ξ = 0.1 加反推函数（之前） | ξ = 0.01 不加函数（现在） |
| --- | --- | --- |
| T1 高斯扩散，方差增长 / 2Dt | 0.993–0.994 | 0.993–0.994 |
| T2 标量守恒，相对变化 | < 1.3×10⁻⁹ | 8×10⁻¹⁰ |
| T5 位移修正对线性场的残差 | 6.6×10⁻⁵ | 8.2×10⁻³ |
| T6 ν_t 与解析值之比，二维 Couette | 0.997 | 0.988 |
| Couette 稳态剖面最大偏差 | 0.25% | 0.24% |
| 二维方腔 1200 步 | 活粒子数不变，溢出 0 | 活粒子数不变，溢出 0，244 步/s |

- T5 和 T6 的偏差就是存储的逆剩下的 0.8–0.9%，与预期一致。T5 对应的位移修正默认关闭，T6 的 1.2% 远小于 Smagorinsky 系数本身的不确定度。
- T1 不变，因为扩散项的归一化不经过存储的逆。
- 搅拌槽 4 mm 在 ξ = 0.01 下跑 3 s 稳定，见评估日志。
