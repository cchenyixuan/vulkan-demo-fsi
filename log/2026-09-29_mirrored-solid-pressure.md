# 2026-09-29 固体压力的成对镜像：实现与测试（未通过，不能用于正式算例）

## 背景

加背景压力 p_b 后总力矩和平均速度向 Fluent 靠拢，但速度切片显示槽上部的湍流结构消失，
怀疑 p_b 带来了数值阻尼。用户决定试成对镜像的固体压力。计划是：默认关闭的选项，改三处代码，
五个本机短算例逐项验证，通过后再跑搅拌槽 30 s。

**结论：五个测试里只有 Couette 通过。成对镜像目前不能用于正式算例。** 测试过程中有三个对现有代码的发现，见"发现"一节。

## 合作者原来的代码

- `density.comp`：固体粒子每步从 ρ₀ 出发，只对流体邻居求和得到一步的密度增量，P_s = EOS(ρ₀ + dt·(Dρ/dt)_s)，之后密度重置为 ρ₀。
- `force.comp`：流体与固体之间的压力对与流体之间相同，自身压力为正时用 (P_i + P_j)，否则用 (P_j − P_i)。
- `density.comp` 的密度扩散项对固体邻居用 ψ = ρ₀ − ρ_i。
- 转子受力：以转子粒子为主体走一遍 `force.comp`，用转子自己的修正矩阵和 P_s，邻居包括其他转子粒子。
- 壁面粒子在 `force.comp` 里直接返回，不计算受力。

## 我们改成了什么

全部是默认关闭的选项，不改变现有算例。

| 选项（case.yaml 的 numerics 块） | spec 常量 | 含义 |
| --- | --- | --- |
| `solid_pressure: increment` | 35，取 0 | 原来的做法（默认） |
| `solid_pressure: mirror` | 35，取 1 | 成对镜像，流体与固体之间始终用对称形式 |
| `solid_pressure: mirror_tic` | 35，取 2 | 成对镜像，流体与固体之间按流体压力走 TIC 切换 |
| `solid_reaction_force: true` | 36 | 固体受力按反作用求和；镜像模式下强制打开 |
| `solid_pressure_offset: p_w` | 37 | 镜像模式下固体压力再加常数 p_w，只作用于流体与固体之间 |

成对镜像的公式（`force.comp`，流体 i 与固体 j）：

```
P_j = P_i + ρ_i (g − a_j)·(x_j − x_i) + p_w
```

a_j 对壁面为 0，对转子为向心加速度 −ω² r_⊥（`helpers.glsl` 的 `solid_particle_acceleration`）。

反作用受力（`force.comp` 的 `solid_reaction_acceleration`）：固体粒子 j 对每个流体邻居 i，用 i 的修正矩阵、密度、压力和 TIC 判断，
算出 i 从 j 受到的加速度（压力加粘性），再取反：

```
a_j = − Σ_i (m_i / m_j) a_(i←j) + g
```

其他改动：

- `simulator_v1.py`：`readback_boundary_forces()` 返回壁面粒子的位置和受力。
- `_check_blade_leak_tracking.py`：力矩日志增加 wall_torque、baffle_torque、wall_fx、wall_fy、wall_fz 五列（没有反作用受力时写 nan）。
  挡板的判定：壁面粒子中半径在 100–139.5 mm、高度大于 0 的。
- `_check_buoyancy_force.py`：增加 `--solid-pressure`、`--hydrostatic`，输出压力随深度的分布、最大流速、越过壁面的粒子数、壁面竖向受力。
- 搅拌槽生成器：`--solid-pressure`、`--solid-reaction-force`、`--solid-pressure-offset`。
- `density.comp` 的密度扩散项**没有改**（试过两种改法都不行，见测试 1）。

## 测试结果

### 测试 1：开重力的静止方箱（未通过）

4 mm，h/dx = 3，边长 120 mm，c₀ = 12 m/s，g = 9.81 m/s²，箱中央有一个不动的方块。静水压初始密度，p_b = 1500 Pa。

| 配置 | 结果 |
| --- | --- |
| 原来的做法，不加初始密度和 p_b | 流体持续下沉，0.18 s 时平均竖向速度 −0.38 m/s，底层压力约 500 Pa（应为 1177 Pa），1200 步时已有 3,339 个粒子越过箱壁 |
| 原来的做法，静水压初始密度加 p_b | 同样下沉并穿壁，3000 步丢失 306 个粒子 |
| 镜像，扩散项对固体取零，关掉位移修正 | **稳定**：1500 步无粒子丢失，最大流速 0.13 m/s，压力中位数 2022–2123 Pa（应为 2089 Pa），底层 2479–2667 Pa（应为 2618 Pa） |
| 镜像，扩散项对固体取零，开位移修正 | 0.075 s 后底部棱边处的流体进入箱壁，随后发散 |
| 镜像，扩散项对固体取带重力修正的镜像密度 | 净质量源：静止流体的压力 100 步内上升 250 Pa |
| 镜像，扩散项不改（ψ = ρ₀ − ρ_i），开位移修正 | 静水压消失，压力中位数降到 p_b 附近，流体穿壁 |
| 镜像加 TIC，不加 p_b | 不发散，但密度持续下降，3000 步时压力中位数 −3944 Pa |

只有"镜像、扩散项对固体取零、关掉位移修正"这一种组合能托住静水压。

## 发现

### 1. 原来的壁面托不住静水压

测试 1 的第一、二行。这也说明 9 月 29 日上午的静水浮力测试（读回值是理论值的 0.2–0.5 倍）是无效的：
当时箱子里的流体一直在穿壁下沉，那次测试关了 defrag，活粒子数不更新，所以没有发现。
质量系数 1.2187 的结论不受影响，它是用 Couette 力矩和角动量通量验证的。

### 2. 壁面的 ρ₀ 同时是"压力汇"和"稳定器"

密度扩散项对固体邻居用 ψ = ρ₀ − ρ_i，把近壁流体的密度拉向 ρ₀。

- 开重力时它吸走静水压。
- 但它也吸收了位移修正造成的密度漂移。位移修正只改位置，连续性方程里没有对应的项；
  把壁面这一项去掉之后，开着位移修正的静止流体密度会一直漂移。

所以开重力的问题不只是固体压力，还涉及位移修正与连续性方程的一致性（δ-ALE 要解决的就是这个）。

### 3. 原来的做法里，转子与流体之间的成对力很小，而且方向相反

测试 5 第一行：把转子受力按"流体从转子粒子受到的力的反作用"来算，力矩是 +8 到 +13 mN·m；
原来的读法是 −71 到 −92 mN·m。

解释：叶片背面的流体压力为负，走 TIC 形式 (P_s − P_f)，这个量是正的，
所以背面的流体被叶片推开，反作用把叶片往前推；正面则把叶片往后推。两者大部分抵消。

而角动量通量法显示流体确实以约 35–37 mN·m 的速率获得角动量（9 月 29 日日志）。
两者的差别只能来自流体与流体之间的 TIC 形式：(P_j − P_i) 不是成对反作用的力，本身可以产生净动量。
这一条是推断，没有逐项核算流体之间的贡献。它意味着原来读法的力矩与通量法相符，不代表力是经由叶片传给流体的。

### 4. 对称形式在负压下不稳定

测试 5 第二行：镜像模式下流体与固体之间始终用对称形式，负压区的流体被吸向固体，0.39 s 内丢失 3% 的粒子。

## 目前的状态

- 镜像加 TIC：搅拌槽短算例稳定，但背面的吸力传不到叶片上（力矩只有约 35 mN·m），与原来的问题相同。方腔里会漏。
- 镜像加 p_b：搅拌槽短算例稳定，力的交换是成对守恒的，但 p_b 的数值阻尼问题还在。
- 没有找到"不加全局背景压力、又能把负压传到叶片上、又不漏"的组合。

30 s 的算例没有提交。

## 有什么影响

- 所有新选项默认关闭，现有算例的着色器行为不变（spec 常量在编译期消去）。
- 现有算例没有重跑回归。Couette 在原来的模式下与之前的结果一致（速度剖面误差 0.24%，力矩比 1.036）。

## 需要合作者确认

1. 壁面密度固定为 ρ₀、每步重置，是否有意用它来稳定位移修正带来的密度漂移。
2. 开重力的算例他是怎么跑的（静水压靠什么托住）。
3. 负压区的力应当怎样传到固体上。
