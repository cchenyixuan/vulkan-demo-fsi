# 2026-09-27 标量输运（示踪剂、底物等随流体粒子携带的浓度场）

本次提交为验证计划第 5 步（标量输运）实现核心功能，并为第 4 步（混合时间）和 lifeline 做准备。
写得尽量详细，便于合作者逐项核对正确性。所有功能都由算例 `scalars:` 块开启；
没有这个块时，force 使用不含标量代码的构建，其余 kernel 中的标量路径由特化常量关闭，
结果（第 6.1 节）和速度（第 7 节）都与改动前一致。

## 1. 功能概览

- 流体粒子携带最多 12 个标量场（4 个一组打包成 vec4，最多 3 组）。
- 对流由粒子运动完成；扩散用 SPH 拉普拉斯算子，写在 force.comp 已有的邻居循环里，不增加邻居遍历。
- 扩散系数 = 分子扩散 D_m + 可选的 Smagorinsky 亚格子扩散 ν_t / Sc_t。ν_t 在 density.comp 中计算，**只用于标量，不进动量方程**。
- predict.comp 用 Kahan 补偿累加施加每步增量，然后处理示踪剂注入（脉冲期间把注入球内流体粒子的浓度设为给定值）。
- 探针：主机端对探针点附近流体粒子做 Shepard 核加权平均，按步数间隔记录；同时记录每个场的守恒总量 Σ m_i C_i。
- 新增永久粒子编号 particle_uid（set 0 binding 10，原先注释里预留给 GlobalIdBuffer 的位置）：上传时等于 pid，随 defrag 搬运，
  lifeline 追踪单个粒子要用它。
- force.comp 编译成两个 SPIR-V：不带标量的 force.comp.spv 与改动前的 kernel 完全相同；带标量的 force_scalar.comp.spv
  只在算例有 `scalars:` 块时使用（原因见第 7 节）。
- 三个数值开关（均为特化常量，便于消融对比）：位移修正（默认关，理由见第 4.6 节）、Kahan 补偿（默认开）、局部有界限制器（默认开，只在位移修正打开时有作用）。

## 2. 用法

### 2.1 算例配置

```yaml
scalars:
  fields:                         # 1..12 个场，按顺序打包：第 k 个场在 vec4 k//4 的分量 k%4
    - {name: tracer_01, diffusivity: 1.0e-9, turbulent: true, initial: 0.0}
  sgs:                            # 可省略，默认关闭
    enabled: true
    smagorinsky_cs: 0.1
    filter_width: null            # Δ，默认 = 粒子间距 dx
    turbulent_schmidt: 0.7
  injections:                     # 可省略；同一时刻最多 4 个脉冲同时有效
    - {field: tracer_01, center: [0.0, 0.4055, 0.1164], radius: 0.0106, start: 25.0, duration: 1.0, value: 1.0}
  probes:                         # 可省略
    radius: 0.009                 # Shepard 平均半径，默认 = h
    points:
      - {name: probe_1, position: [-0.127, 0.4015, -0.018]}
  shift_correction: false         # 默认 false
  compensated_sum: true           # 默认 true
  bounds_limiter: true            # 默认 true
```

- `diffusivity` 分子扩散系数 D_m（m²/s）；`turbulent: false` 的场永远不接收 ν_t（例如附着在粒子上的生物量，不应在粒子间被抹开）。
- 浓度按"单位质量"定义：对流不改变粒子上的值，守恒量为 Σ m_i C_i。
- 固体粒子（壁面、转子）的标量恒为 0，且不参与任何标量求和，因此壁面是零通量边界。

## 4. 方程与离散

### 4.1 扩散项（force.comp，流体自身、流体邻居）

目标方程 (1/ρ)∇·(ρD∇C)。采用 Brookshaw / Morris 形式，D 取两粒子的算术平均，成对体积取 2 m_j / (ρ_i + ρ_j)：

```
(dC/dt)_i = Σ_j  2 m_j (D_i + D_j) / (ρ_i + ρ_j) · λ_ij · (C_i − C_j) · (x_ij·∇W_ij) / (r_ij² + η²)
λ_ij = ( d / tr M_i + d / tr M_j ) / 2,    tr M = Σ_j V_j (x_j − x_i)·∇W_ij,    η² = 0.01 dx²
```

D_i = D_m + w · ν_t,i / Sc_t（w 为该场的 SGS 权重 0 或 1）。D_i = D_j = D 时，系数约等于 2 V_j D，即标准的 SPH 拉普拉斯算子。

- x_ij = x_i − x_j，∇W_ij 为未修正的核梯度（对 x_i 求导）。x_ij·∇W_ij = r W'(r) < 0，所以局部极大值会衰减。
- **守恒性**：m_i 乘以成对系数得 2 m_i m_j (D_i + D_j) / (ρ_i + ρ_j)，它和 λ_ij、x_ij·∇W_ij 都关于 (i, j) 对称，
  而 (C_i − C_j) 反对称，所以每一对对 Σ_i m_i C_i 的贡献正好抵消，标量总量守恒到舍入误差。
- **为什么是算术平均**：最初按 Cleary & Monaghan（1999）用了 ρD 的调和平均，它在 D 突变处（例如两种材料的界面）更好，
  但每个邻居每个分量要做一次除法。这里固体邻居已显式排除，D 在流体内连续变化，
  算术平均是 Morris 等（1997）粘性项的标准做法，每对只需一次标量除法。D_i = D_j 时两者完全相同，T1 结果不变。
  D_m = 0 且不接收 ν_t 的场（例如附着的生物量）D 恒为 0，通量为零。
- **邻居类型不用分支**：流体标记和 d/tr M 由 correction.comp 预存在同一个 vec4 里。force 对每个邻居无条件地
  读取它和浓度，再用标记（0 或 1）乘掉固体邻居的贡献；固体粒子的浓度恒为 0，读取是安全的。
  之前"先读标记、再按标记分支、分支内再读浓度"的写法把两次读取串成了依赖链。
- **分量掩码**：浓度按 vec4 读入后乘以 scalar_component_mask()，这个掩码由特化常量 SCALAR_FIELD_COUNT 决定。
  管线特化后，多余分量是编译期常量 0，相应的运算和寄存器都被删掉。只有 1 个场时，force 因此快约 7%。
- 两处偏离教科书 Brookshaw 形式的修改，都由下面 4.2 的测量和计算驱动。

### 4.2 拉普拉斯算子的归一化（重要，请重点核对）

在测试晶格（简单立方、h/dx = 3、按"Σ_{j≠i} V W = 1"校准的粒子体积，V = 1.219 dx³）上，对 f = r² 直接计算离散算子，精确值为 6：

| 变体 | L[r²] | 相对误差 | T1 实测方差增长比 |
| --- | --- | --- | --- |
| 原始 Brookshaw，η² = 0.01 h²（代码里的 EPS_H_SQUARED） | 6.916 | +15.3% | 1.149 |
| 原始 Brookshaw，η² = 0 | 7.263 | +21.0% | — |
| 未正则化 M⁻¹ 归一化，η² = 0.01 h² | 5.714 | −4.8% | — |
| 存储的（正则化的）M⁻¹ 取两粒子平均，η² = 0.01 dx² | 5.511 | −8.2% | 0.918 |
| λ_ij 归一化（未正则化迹），η² = 0.01 dx²（采用） | 5.966 | −0.56% | 0.993 |

- 原始算子偏大，是因为校准后的体积使 −Σ V x_ij·∇W = tr M = 3.63，而精确值是 d = 3。
- **迹恒等式**：若 M = (tr M / d) I（规则晶格上成立），则 −Σ_j V_j x_ij·(d / tr M)∇W_ij = d，
  于是 λ 归一化后的算子对 r² 精确；再利用立方对称性 Σ x̂_a x̂_b w = δ_ab Σ w / 3，对任意二次函数都精确。
- **不直接用存储的 M⁻¹**：correction.comp 在求逆前给对角线加 ξ = 0.1，而这个晶格上 M 的对角元约为 1.21，
  所以存储的逆偏小 7.6%（读回 GPU 值：0.76308，(1.2105 + 0.1)⁻¹ = 0.76307；未正则化应为 0.82610）。
  因此在 correction.comp 里把正则化之前的 d / tr M 存进原本空闲的 correction_inverse[2i+1].z，只供标量使用，不改变任何动量或密度项。
- **η² 改用 0.01 dx²**：EPS_H_SQUARED = 0.01 h² 相当于 0.09 dx²，使最近邻的贡献少 8%，整体少约 5%。η 只需保证重合粒子不发散。
- **各向异性**：λ 是各向同性的归一化。在粒子分布明显各向异性的地方（例如壁面附近、强剪切区），
  它只修正整体尺度，不修正方向性误差；Brookshaw 算子在无序粒子上本来就不一致，靠 PST 维持准规则分布。

### 4.3 浓度梯度与位移修正（可选，默认关）

```
∇C_i = M_i⁻¹ Σ_j V_j (C_j − C_i) ∇W_ij        （M⁻¹ 用未正则化的逆，一阶一致）
ΔC_i += shift_i · ∇C_i                       （shift_i 与 predict 加到位置上的是同一个量）
```

- 未正则化的逆由 `unregularized_correction_inverse()` 从存储值恢复：M = stored⁻¹ − ξ I，再求逆；
  二维时 z 行列在 correction.comp 里被设为单位阵、没有加 ξ，所以只修正 xx 和 yy；M 本身接近奇异时退回存储值。
- 实现上先对原始 ∇W 求和，循环后再乘 M⁻¹，并利用 M⁻¹ 对称，把它作用到 shift 上：shift·(M⁻¹g) = (M⁻¹shift)·g。
- 梯度只对流体邻居求和，而 M 包含全部邻居，所以壁面附近法向梯度偏小，相当于零梯度（Neumann）边界。

### 4.4 局部有界限制器（可选，默认开，只在位移修正打开时起作用）

把增量截断到 ΔC_i ∈ [min − C_i, max − C_i]，范围取自本粒子和所有流体邻居的当前值，使 C_i + ΔC_i 不越界。
扩散部分本身是单调的（所有成对系数为正，扩散数远小于 1），不需要限制器；它只和位移修正一起启用。
注意必须直接截断增量：最初写成 clamp(C_i + ΔC_i, min, max) − C_i，当 ΔC_i 小于 C_i 的半个 ulp 时，
C_i + ΔC_i 在 float32 中就等于 C_i，增量被抹成 0，Kahan 补偿也救不回来（T4 在一轮回归中因此完全不扩散）。

### 4.5 Kahan 补偿累加（predict.comp，默认开）

```
y = ΔC − c;   t = C + y;   c = (t − C) − y;   C = t        （precise 限定，禁止编译器重排）
```

真实值为 C − c（主机端 `scalar_snapshot()` 按此恢复）。必要性：弱可压的时间步很小（3 mm 槽约 6.6×10⁻⁵ s），
主体区 D_t 约 10⁻⁷ m²/s 时，每步增量约为 4×10⁻⁶ ΔC；到混合后期，邻居间浓度差 ΔC ~ 10⁻³，增量低于 C ≈ 0.5 处半个 ulp（3×10⁻⁸），
在普通 float32 累加里每一步都会被舍入掉。T4 用刻意构造的算例证实了这一点（第 6.5 节）。
注入把分量设为给定值时，同时把对应的补偿项清零。

### 4.6 为什么位移修正默认关（请重点讨论）

δ⁺ 的粒子位移修正（PST）让粒子相对流体移动。不修正时，粒子带着原来的浓度走，产生人为输运；
修正时（ΔC = shift·∇C，一阶泰勒插值），在陡峭前沿既不守恒也无界。测量数据（4 mm 碟底槽，c₀ = 20 U_tip）：

**位移造成的偏离**（`_check_shift_dispersion.py`：跟踪 2 万个流体粒子，按 uid 映射，累加每步的 shift）：

| 时间间隔 | 累计偏离均方根 | 与完全同向累加之比 | 等效扩散系数估计 |
| --- | --- | --- | --- |
| 1 步 | 7.2 µm（0.0018 dx） | 0.99 | — |
| 0.0036 s | 0.29 mm | 0.97 | 3.9×10⁻⁶ m²/s |
| 0.031 s | 2.0 mm | 0.79 | 2.2×10⁻⁵ m²/s |
| 0.26 s | 11.7 mm | 0.53 | 8.6×10⁻⁵ m²/s（仍在增长） |

- 每步只有 0.0018 dx，但方向高度持续，折合相对流体的速度约 8 cm/s（均方根），量级与"剪切率 × dx"相当：
  剪切不断扭曲粒子排布，PST 不断把它推回均匀。
- 0.26 s 内逐渐失去方向相关性，向随机游走过渡，等效扩散约 10⁻⁴ m²/s，比 Smagorinsky 的 D_t 大
  （桨叶区中位数约 1×10⁻⁵，主体约 5×10⁻⁸）。

**T7 脉冲测试的三个变体**（第 6.7 节）：

| 变体 | 脉冲结束后 0.53 s 内总量变化 | 值域 |
| --- | --- | --- |
| 不修正（默认） | 7.8×10⁻¹¹ | [0, 1] |
| 修正，不加限制器 | +0.51% | [−0.30, 1.20] |
| 修正加限制器 | +2.6%（限制器把负的下冲抬到 0，相当于加量） | [0, 1] |

（最终代码的结果；开发中间版本的数值略有不同，结论相同。）

结论与取舍：
- 默认不修正：浓度精确守恒且有界。求解器本身也不对密度和速度做 shift 后的泰勒修正（predict 只移动位置），两者处理方式一致。
- 代价：位移修正造成的偏离相当于约 10⁻⁴ m²/s 的额外数值扩散，与 dx 一阶相关，会随加密减小。
  对槽尺度混合（L²/D ≈ 900 s，远长于混合时间 25 s）影响有限，但会主导亚粒子尺度的混合；
  混合时间验证时，计划用修正开和关各跑一次来量化 t95 对它的敏感性。
- 原理上的解决方案是守恒的 ALE 形式（δ-ALE-SPH，Antuono 等 2021）。它会同时改变密度和动量方程，需要与合作者讨论。

### 4.7 Smagorinsky ν_t（density.comp）

```
G = ∇v_i = [Σ_j V_j (v_j − v_i) ⊗ ∇W_ij] M_i⁻¹     （未正则化 M⁻¹，一阶一致；固体邻居按其壁面或转子速度计入，即无滑移）
S = (G + Gᵀ)/2,   |S| = sqrt(2 S:S),   ν_t = (C_s Δ)² |S|
```

- 放在 density.comp，是因为它已经读取邻居速度、体积和核梯度；force.comp 在同一步读取 ν_t。
- density 与 force 之间，原有的"计算→传输→计算"屏障链只声明了传输访问，所以开启 SGS 时额外插入一个"计算→计算"屏障。
- 只对流体粒子计算和写入。

### 4.8 注入与探针

- 脉冲在 start ≤ t_{n+1} < start + duration 期间有效，predict 在新位置 x_{n+1} 处判断粒子是否在球内。
- 探针值为 C(p) = Σ_j C_j W(|p − x_j|; R) / Σ_j W，只对活流体粒子，Wendland C4 形状，R 默认为 h；探针周围无流体粒子时返回 NaN。

## 5. 每步执行顺序（开启标量时）

```
predict       : 位置/速度更新；流体 C ← C + ΔC_{n}（Kahan）；有效脉冲覆盖注入球内的值
update_voxel  : 不变
correction    : 不变，另存 d / tr M（未正则化）和流体标记到 correction_inverse[2i+1].zw
density       : 不变；开启 SGS 时计算并写 ν_t
(计算→计算屏障，仅 SGS) → density 暂存区拷回
force         : 不变；另算扩散项（可选的 ∇C 与限制器），写 ΔC_{n+1} 到 scalar_delta
defrag（每 10 步）: 另搬运 binding 10–14
```

启动阶段：bootstrap 的 force 为第一步准备 ΔC_0；初始条件用 `write_scalars()` 在 bootstrap 之前写入。

| 对比 | 最大 |dx| | 最大 |dv| | 动能 |
| --- | --- | --- | --- |
| 改动前 vs 改动前（运行间噪声） | 8.0×10⁻⁷ m | 2.9×10⁻⁶ m/s | 相同 |
| 改动前 vs 改动后（开发中 4 次，最后一次为最终版本） | 4.8×10⁻⁷ 到 7.2×10⁻⁷ m | 2.4×10⁻⁶ 到 4.4×10⁻⁶ m/s | 相同 |

与运行间噪声同一量级，没有系统偏差；活粒子数、材料一致，溢出计数全 0。速度见第 7 节。

### 6.2 T1 高斯扩散（D = 3×10⁻⁵ m²/s，σ₀ = 8 mm，立方体半边长 50 mm，dx = 2 mm，每 10 步 defrag）

12.5 万个流体粒子（50³），外加 3 层壁面，c₀ = 1 m/s，dt = 9×10⁻⁴ s，2222 步。
按粒子加权计算每个坐标方向的方差 σ²(t) = Σ m C |x|² / (3 Σ m C)，与 σ₀² + 2Dt 比较；
解析解 C = (σ₀²/σ²)^{3/2} exp(−r²/(2σ²))。

| t (s) | σ² 增长 (m²) | 2Dt (m²) | 比值 | 峰值 | 均方根误差 / 峰值 |
| --- | --- | --- | --- | --- | --- |
| 0.5 | 2.986×10⁻⁵ | 3.002×10⁻⁵ | 0.994 | 0.560 | 5.4×10⁻⁴ |
| 1.0 | 5.965×10⁻⁵ | 5.999×10⁻⁵ | 0.994 | 0.373 | 8.1×10⁻⁴ |
| 1.5 | 8.947×10⁻⁵ | 9.002×10⁻⁵ | 0.994 | 0.270 | 9.9×10⁻⁴ |
| 2.0 | 1.191×10⁻⁴ | 1.200×10⁻⁴ | 0.993 | 0.207 | 1.1×10⁻³ |

剩下的 0.7% 偏慢与 η² = 0.01 dx² 的预期影响（−0.56%）一致。质心保持在原点（10⁻⁹ m 量级）。
由于每 10 步做一次 defrag，这个测试同时检验了标量缓冲随 defrag 的搬运。
注：粒子位于格子中心，离原点最近的粒子在 r = √3 dx/2，所以 t = 0 的峰值是 0.977，不是 1。

### 6.3 T2 守恒、T3 不扩散的场（同一次运行）

- T2：2 s 内 Σ m C 的相对变化始终小于 1.3×10⁻⁹（按 float64 对补偿后的值求和）。
- T3：D = 0、不接收 ν_t 的场，每个粒子的值（按 uid 对应）完全不变（最大变化为 0），总量相对变化小于 10⁻¹³。
  默认不做位移修正，所以不扩散的场只随粒子移动。

### 6.4 T5 位移修正（开启修正时的实现正确性）

20³ 个流体粒子，初始位置在格点附近随机扰动 ±0.25 dx，c₀ = 1 m/s，300 步，不做 defrag，粒子编号不变。
线性场 C = 1 + 10x，D = 0。扰动会引起压力弛豫和很强的位移修正：内部粒子 300 步累计位移的均方根为 0.21 dx。
检查量为 C(t) − C(0) − 10 Σ shift_x。只看距壁面超过 h 的 2746 个内部粒子。

| 变体 | 残差均方根 / 预期变化均方根 | 最大残差 |
| --- | --- | --- |
| 打开位移修正 | 6.6×10⁻⁵ | 4.5×10⁻⁶ |
| 关闭位移修正 | 1.000 | 1.6×10⁻² |

说明修正项的符号正确，未正则化 M⁻¹ 给出的梯度对线性场精确（用存储的正则化矩阵时残差为 7.7%，见 7b 节）。

### 6.5 T4 Kahan 补偿

15³ 个流体粒子，C = 1 + 0.1 exp(−r²/(2σ₀²))，σ₀ = 4 mm，D = 2×10⁻⁹ m²/s，dt = 9×10⁻⁴ s，100000 步（90 s）。
每步的最大增量为 2.9×10⁻⁸，小于 C ∈ [1, 2) 处半个 ulp（5.96×10⁻⁸）。

| 变体 | 峰值衰减比 | 方差增长 / 2Dt | 凸起部分总量变化 |
| --- | --- | --- | --- |
| 解析解 | 0.9672 | 1 | 0 |
| Kahan 补偿（默认） | 0.9714 | 0.985 | −4×10⁻¹¹ |
| 普通 float32 累加 | 1.0000 | 0 | 0 |
| Kahan 补偿 + 位移修正 | 0.9714 | 0.981 | +8.4×10⁻⁴ |

- 普通 float32 累加完全不扩散：每一步的增量都被舍入掉。
- σ₀ 只有 2 dx，所以离散误差比 T1 大（方差增长比 0.985）。峰值衰减偏慢，这与核平滑相符。
- 打开位移修正后，90 s 内凸起部分的总量变化 8.4×10⁻⁴，关闭后为 4×10⁻¹¹，说明这一漂移完全来自位移修正项。

### 6.6 T6 Smagorinsky ν_t（二维 Taylor–Couette，Ω = 2 rad/s，r_i = 0.05，r_o = 0.10，dx = 1 mm，C_s = 0.1，40000 步 = 7.5 s）

解析稳态 u_θ = A r + B/r 的应变率 |S| = 2|B|/r²。结果（避开两壁各一个核半径）：
ν_t（GPU）/ 解析值 = 0.997（各径向分箱在 0.993 到 1.001 之间）；相对用 SPH 速度剖面数值求导得到的 |S| 为 0.998。

调试过程中发现并修正了两个问题：
1. 最初 ν_t 被当作临时量、不随 defrag 搬运。第 40000 步正好触发 defrag，读回的 ν_t 与粒子错位，看起来沿半径几乎是平的。
   主机上按同一公式重算，结果和 GPU 完全一致（比值 1.0000），说明模拟本身没问题，问题出在读回。现在 binding 14 也随 defrag 搬运。
2. 速度梯度最初用存储的（正则化的）M⁻¹，ν_t 偏小 8%；改用未正则化的逆后比值为 0.997。

### 6.7 T7 搅拌槽脉冲（4 mm 碟底，两个示踪剂，脉冲 0.3–0.5 s 与 0.6–0.8 s，SGS 开，每 10 步 defrag，1.05 s）

注入、探针、ν_t、defrag 和转子同时工作，三个变体各 12000 步，均无溢出、无 NaN。脉冲期间总量从 0 升到 6.7×10⁻³（单位 kg·C），
下一个示踪剂在 0.6 s 准时开始。1.05 s 内示踪剂还没到达探针，两个探针读数都是 0（注入点在上部慢区，约 2 cm 深）。
ν_t 分区统计（中位数 / 95 分位，m²/s）：Rushton 区 7.8×10⁻⁶ / 1.8×10⁻⁵，PBT 区 8.5×10⁻⁶ / 2.0×10⁻⁵，
上部主体（y > 0.3 m）3.8×10⁻⁸ / 1.2×10⁻⁷，与此前的量级估算一致。三个数值变体的比较见 4.6 节。

## 7. 性能（RTX 4070 Ti SUPER，3 mm 平底槽 124 万粒子，静止时每步各 kernel 计时，毫秒）

改动前的代码单独检出为 git worktree，和新版交替测量各 3 次（取平均，括号内为范围），带标量的配置各测 2 次。
带标量的配置在 3 mm 算例后面追加 `scalars:` 块：1 个场、1 个场加 SGS、12 个场加 SGS。

| 配置 | predict | correction | density | force | 各 kernel 之和 |
| --- | --- | --- | --- | --- | --- |
| 改动前 | 0.24 | 3.23 | 3.69 | 4.33（4.32–4.33） | 11.61 |
| 新版，无标量 | 0.24 | 3.23 | 3.70 | 4.34（4.32–4.36） | 11.64 |
| 1 个场 | 0.37 | 3.22 | 3.67 | 6.03 | 13.45 |
| 1 个场 + SGS | 0.37 | 3.22 | 4.47 | 6.16 | 14.40 |
| 12 个场 + SGS | 0.65 | 3.23 | 4.48 | 10.52 | 19.05 |

- 无标量时与改动前一致。最初只用特化常量屏蔽标量代码时，force 多了 0.23 ms（+5%），交替测量下稳定存在；
  用预处理器把标量代码整段去掉后，恢复到 4.33 ms。说明驱动在特化时没能删干净，所以改为编译两个 SPIR-V。
- 1 个场：每步多 16%，其中 force 多 39%。force 原本每个邻居读 3 次数据，现在每个流体邻居多读 2 次
  （浓度，以及 d/tr M 和流体标记），并多一组累加寄存器。优化过程见 7b 节第 8 条（最初为 +100%）。
- SGS 让 density 多 0.8 ms，用于速度梯度的外积累加。
- 12 个场时每步多 64%。混合时间验证用 10 个示踪剂，如果要省时间，可以分成 3 批，每批 4 个。
- 当初估计 1 个场每步只多 3–5%，实测是 16%，低估了。原因是 force 的邻居循环受访存延迟限制，额外的读取和寄存器压力影响更大。

## 7b. 开发过程中发现并修正的问题（按时间顺序）

1. **拉普拉斯算子偏大 15%**：原始 Brookshaw 形式在 h/dx = 3 的晶格上，加上校准后的体积，扩散快 15%（T1 方差增长比 1.149）。
   在同一晶格上直接计算离散算子得到 +15.3%，两者吻合。改用修正矩阵归一化后，发现下一条问题。
2. **KCG 矩阵的 Tikhonov 偏差 7.6%**：改用存储的 M⁻¹ 后，扩散反而慢 8%（0.918）。读回 GPU 上的矩阵，
   对角元为 0.76308，正好等于 (1.2105 + 0.1)⁻¹，即正则化后的值。于是改为用未正则化的 d / tr M，得到 0.993。
   这一偏差同样存在于动量方程中，见第 8 节第 1 条。
3. **η² 取得偏大**：EPS_H_SQUARED = 0.01 h² = 0.09 dx²，使拉普拉斯算子整体少约 5%。标量改用 0.01 dx²。
4. **位移修正的正确性**（T5）：修正项用未正则化的逆后，残差从 7.7% 降到 0.01% 以下，与第 2 条一致。
5. **读回的 ν_t 与粒子错位**（T6）：ν_t 最初当作临时量，不随 defrag 搬运，而 T6 最后一步正好触发 defrag。
   主机重算结果与 GPU 完全一致（比值 1.0000），说明模拟本身正确。现在 binding 14 也随 defrag 搬运。
6. **位移修正与守恒、有界**（T7 和位移测量）：位移修正在陡峭前沿不守恒也不有界，加限制器更不守恒。
   因此改为默认关闭，见 4.6 节。
7. **限制器的舍入问题**（T4 回归）：见 4.4 节，改为直接截断增量，并且只在位移修正打开时启用。
8. **性能**：开启 1 个标量时，force 最初慢一倍（4.6 → 9.5 ms）。依次做了四项优化：
   用预存的流体标记加乘法代替两次相互依赖的材料查表（7.3 ms）；每个邻居每个分量的除法改为每对一次（7.2 ms）；
   去掉依赖于邻居类型的分支（6.6 ms）；按场数对分量加掩码（6.1 ms）。
   另外，把 force 编译成带标量和不带标量两个版本，消除了无标量时 0.23 ms 的开销。结果见第 7 节。

## 8. 给合作者的发现与待讨论问题

1. **KCG 正则化偏差（影响整个求解器，本次未改动）**：correction.comp 求逆前对角线加 ξ = 0.1（绝对值），
   而 h/dx = 3 的三维晶格上 M 的对角元约 1.21，所以存储的 M⁻¹ 比精确值小 7.6%（读回值 0.76308 对精确 0.82610）。
   压力梯度、粘性项、δ 密度扩散都用这个修正梯度，因此都被整体缩小约 7.6%。在二维 h/dx = 5 的 Couette 算例中约为 8%。
   稳态 Couette 剖面与粘度无关，所以之前 0.25% 的验证检测不到这一点。建议考虑改成相对正则化（例如 ξ · tr M / d，ξ ~ 10⁻³）；
   这会改变动量方程，需要合作者决定，并重跑方腔和功率数。
2. **位移修正与标量**（4.6 节）：默认关闭的取舍，以及是否采用 δ-ALE 的守恒形式。
3. **拉普拉斯归一化**（4.2 节）：λ 各向同性归一化和 η² = 0.01 dx² 的选择。

## 9. 已知局限与后续
