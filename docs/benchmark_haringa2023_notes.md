## 3. 54 m³ 罐的生物和 lifeline 设置

| 项目 | 值 |
| --- | --- |
| 格子 | NX = 120（Δx = 25 mm，约 350 万格点），Co = 0.075 |

| 加料 | F_s = 0.37 mol/s，从混合算例的注入球加入；初始 C_s = 7.8 × 10⁻⁵ mol/kg（10 K_s） |

| parcel | 2500 个无质量粒子，t = 0 时在 y = 3 m、r = 0.5 m、直径 0.2 m 的球内释放，跟踪 2000 s，前 100 s 丢弃；每 0.03 s 记录 q/q_max |
| 区间 | 饥饿 S：q/q_max < 0.05；过量 E：> 0.95；其间为限制 L；0.36 s 滑动平均；转换须越过边界 0.01（如 E 到 L 要 < 0.94） |
| 转换模式 | LEL、LSL（在 E 或 S 里的停留），ELE、SLS、ELS、SLE（经过 L 的四种） |
| arc | 阈值 0.05，记录相邻两次越过阈值之间的时长 τ_arc；阈值以上的段记录最大 q/q_max |
| 代谢响应 | 后处理：lifeline 拼成 80 h 序列，喂给 9-pool 模型（附录 A），15 条平均 |

平均摄取能力 q_max · C_x · V = 1.32 mol/s，加料 0.37 mol/s，所以平均 q/q_max ≈ 0.28。

双向耦合的说明在第 2.3.5 节（第 5 页右栏）：多池模型目前不能直接放进 M-Star 实现双向耦合；作者认为原理上无障碍，
与拉格朗日气泡传质同类；但提醒生物量离散到 parcel 上时，高分辨率下需要很多 parcel 才能避免离散造成的梯度（引 Haringa 等 2017，Chem. Eng. Sci. 157:159）。

## 6. 与我们设定的差别，复现时要注意

1. 他的标量没有亚格子扩散，只有分子扩散和 van Leer 格式的数值扩散；我们的标量有 Smagorinsky 扩散。对照时应做一组关掉标量 SGS 的变体，
   但我们关掉 SGS 后粒子尺度上不混合（9 月 28 日已测），所以至少要保留一个最小的扩散，具体取法需要定。
2. 他的生物量是均匀欧拉场，parcel 只读不扣；我们是每个流体粒子带生物量、本地扣减。均匀生物量时两者的数学模型相同，可以直接对照。
3. 他的 lifeline 是 2500 个无质量粒子；我们的是流体粒子本身。我们可以抽样更多条，统计会更平滑，但要按相同条数做一组以比较噪声水平。
4. 他的 parcel 从罐中部一个小球释放，前 100 s 丢弃；我们如果从全槽抽样，就不需要丢弃期，但为了对照应按相同的释放方式也做一组。
