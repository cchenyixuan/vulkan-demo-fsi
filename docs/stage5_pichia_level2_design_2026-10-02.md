# 阶段五设计方案：级别二模型，毕赤酵母葡萄糖补料

日期：2026-10-02　分支：`test`　状态：方案，模型结构待用户确认；参数待过程数据

用户决定：级别二用毕赤酵母（Komagataella phaffii），碳源葡萄糖，有过程数据。
级别一的方法验证仍用 Haringa 2023 的青霉菌参数（`docs/benchmark_haringa2023_notes.md`），级别二是应用展示。

## 1. 为什么换机理

研究计划 4.2 节的级别二是"生长率弛豫加溢流"，溢流指酿酒酵母的 Crabtree 效应。毕赤酵母是 Crabtree 阴性菌，
好氧下葡萄糖过量基本不产乙醇；乙醇和阿拉伯糖醇主要在缺氧时出现（Baumann 等 2010，BMC Syst. Biol. 4:141）。
我们是单相模型、不算溶氧，所以级别二改为：生理状态有记忆，摄取受生理状态限制，产物生成随生长率变化。
如果过程数据里在葡萄糖过量时测到副产物，再加副产物项。

## 2. 模型

每个流体粒子携带（单位按比量，随粒子输运）：

| 场 | 含义 | 扩散 |
| --- | --- | --- |
| C | 葡萄糖，g/kg | 分子扩散加标量 SGS |
| X | 生物量，g/kg | 无 |
| μ | 细胞当前的比生长率（生理状态），1/s | 无 |
| P | 分泌的产物，g/kg | 分子扩散加标量 SGS（产物溶在发酵液里） |
| U、F、M | 累计摄取、累计加料、累计维持消耗，用于收支 | 无 |

每粒子每步：

    环境供给的摄取     q_env = q_max C / (K_s + C)
    状态允许的摄取     q_dem = (μ + α μ_max) / Y_xs + m_s       当前生长率能处理的底物，α 为余量
    实际摄取           q_s = min(q_env, q_dem)
    实际生长           μ_act = max(0, Y_xs (q_s − m_s))
    生理状态           dμ/dt = (μ_act − μ) / τ                  τ 可分上调 τ_up、下调 τ_down
    生物量             dX/dt = μ_act X
    产物               dP/dt = q_p(μ) X                         q_p(μ) 按过程数据拟合，参照 Maurer 等 2006
    底物               dC/dt = −q_s X,   dU/dt = q_s X,   dM/dt = min(q_s, m_s) X

μ_max 不是独立参数：充分供给的稳态下 μ = Y_xs (q_max − m_s)。上调时 μ 先以 α μ_max / τ 的速率线性增加，接近平衡后按 τ 指数逼近；
下调时实际生长立即随供给下降，μ 按 τ 回落。

双向耦合从哪里来：从饥饿区回到加料区的细胞 μ 低，q_dem 小，吃不完供给的葡萄糖，多余的葡萄糖逃出加料区，改变全槽的底物场和其他细胞的经历。
这是"群体生理异质性反馈到底物场"，级别一（摄取只取决于当地浓度）和 Haringa 的单向方法都表达不了。

两个极限可作检验：α 很大或 τ → 0 时退化为级别一的 Monod（已验证的代码路径）；τ → ∞ 时 μ 冻结，摄取只受 q_dem 限制。

参数来源：

| 参数 | 来源 |
| --- | --- |
| μ_max、K_s、Y_xs、m_s | 用户的过程数据（零维补料分批模型拟合），文献核对 |
| q_p(μ) | 用户的产物数据；形式参照 Maurer 等 2006（Microb. Cell Fact. 5:37） |
| τ、α | 补料分批数据通常辨识不出（充分混合时没有环境波动）；若有脉冲或缩小模型实验可用，否则按计划扫描 |

## 3. 需要的过程数据

| 类别 | 内容 |
| --- | --- |
| 反应器 | 规模和工作体积；罐径、液位、桨型、桨径、转速；挡板；加料点位置；通气方式和转速是否变化 |
| 菌株和工艺 | 启动子（推测为 GAP）；补料方式（恒速、指数、DO-stat 等）和补料浓度；温度、pH |
| 时间序列 | 生物量（干重或 OD 及换算）、残余葡萄糖、补料速率或累计补料量、产物浓度或活性、溶氧、OUR 和 CER（若有）、乙醇和阿拉伯糖醇（若测过） |
| 不同条件 | 不同设定生长率或不同补料速率的批次（用于拟合 q_p(μ)）；不同规模的批次（若有，最有价值） |
| 动态实验 | 葡萄糖脉冲、补料中断或缩小模型实验（若有，用于辨识 τ） |

数据和拟合得到的参数默认放在仓库之外（Dropbox 项目目录 `SPH lifeline/process_data/`），不进 git，除非用户另行决定。

## 4. 数据怎样用

1. 零维补料分批模型（充分混合）拟合数据：同样的方程去掉空间，得到 μ_max、K_s、Y_xs、m_s、q_p(μ)。这也是"理想混合"的参照。
2. CFD：同一工艺放到大罐里（30 L 槽，或 54 m³ 罐），lifeline 给出每个细胞的 μ 历史，汇总得到产率相对理想混合的损失。
3. 若数据有多个规模：用小规模的拟合参数预测大规模，与实测比较。这是最有说服力的验证。

| 5 | 30 L 槽展示：τ 扫描，双向与单向对照（单向：底物场按级别一，μ 和 P 沿 lifeline 离线积分） |

3. 数据和参数是否可以进入仓库或论文（默认都不进仓库）。
