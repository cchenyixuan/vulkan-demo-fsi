## 3. 各项改动

### 3.1 力矩读回的质量系数（读数解释，不改计算）

**原来的代码**：`_calibrate_particle_volume` 令规则晶格上不含自身的核函数求和等于 1，V_p = 1/Σ_{j≠i} W(r_ij)，粒子质量 m = ρ₀V_p。
三维 h/dx = 3 时 V_p = 1.2187 dx³，求解器里流体总质量 36.0 kg，而 29.6 L 水应为 29.5 kg。

**影响**：加速度经 KCG 归一化，与 V_p 无关，流场不受影响；但 `readback_rotor_torque()` 算 Σ m (x − p) × (a − g)，正比于 m，
所以 9 月 29 日以前报告的力矩和功率数都偏大 1.2187 倍。二维 Taylor–Couette 的稳态力矩和静水浮力两个验证都给出这个比值。
之后所有报告的力矩都除以 1.2187。

**需确认**：粒子质量应取 ρ₀dx³ 还是 ρ₀V_p；若取 V_p，读回力矩是否应按同样系数折算。

### 3.2 KCG 正则化 ξ：0.1 改为 0.01（唯一改了默认值的一项）

**原来的代码**：`correction.comp` 在求逆前给 M 的对角线加 ξ = 0.1（绝对值）。规则晶格上 M 的对角元 1.13 到 1.21，存储的逆偏小约 8%，
压力梯度、粘性项、密度扩散、位移都跟着偏小。

**改动**：入库算例和 `common.glsl` 的默认值改为 0.01（偏小 0.8%）。二维 Taylor–Couette 启动过程测得的等效粘度：ξ = 0.1 时 0.76，0.01 时 0.91，0.001 时 0.92（材料值的倍数）。
另一个独立发现：三维 h/dx = 3 晶格上 Morris 粘性算子是精确算子的 0.84 倍，与 ξ 无关；用 1.19 倍材料粘度补偿后 3 mm 和 2 mm 的力矩变化都在 1% 以内。

**需确认**：ξ 的取值；Morris 算子 0.84 的系数是否要在材料粘度里补。

### 3.3 几何（生成器层面，不改求解器）

- 叶片：单层粒子，贴体排布（`--conformal-blades --thin-layers 1 --skin 0`），每片叶片在自己的中面上排规则网格，没有台阶，不漏液（永久编号逐帧追踪，30 s 穿越为 0）。
  从全域格点取粒子的单层叶片在台阶处漏。原来三层加外皮的叶片有效厚度 12.5 mm，真实 2.2 到 2.5 mm。
- 挡板：按 STL 改为 3 块、径向 114.4 到 138.4 mm、厚 2.6 mm、从槽底延伸到顶盖，钟形罩按 STL 加入。原来的挡板宽 13 mm、不到底。
- PBT 叶尖：真实长度 48.2 mm，最大半径 49.1 mm。

### 3.4 背景压力 p_b

**原来的代码**：P = B((ρ/ρ₀)^γ − 1)，槽内平均压力约 0，Rushton 区 31% 到 51% 的粒子处于负压，TIC 频繁切换。

**改动**：`density.comp`

```glsl
float new_pressure = self_params.eos_constant * (pow(density_ratio, POWER_PARAMETER) - 1.0)
                   + BACKGROUND_PRESSURE;
```

密度不变，只抬压力水平。p_b = 2000 Pa 是 1 g 算例的全场平均静水压（ρgH/2）。

**影响**：负压粒子消失；封闭单相槽里物理上无影响，数值上通过 TIC 起作用。单层叶片的 Rushton 随压力水平变（1 g 的 3.6 kPa 对 p_b 的 2.1 kPa：47.2 对 43.1），
薄板不变（48.7 对 49.8），因为薄板的镜像压力由流体自身外推。

**需确认**：是否同意用 p_b 代替重力抬高压力水平（重力的问题见第 4 节）。

### 3.5 壁面压力模型、反作用受力

**原来的代码**（increment）：固体粒子每步从 ρ₀ 出发，只对流体邻居求和得到一步密度增量，P_s = EOS(ρ₀ + dt·(Dρ/dt)_s)，之后重置为 ρ₀。
开重力时它托不住静水压：槽底壁面压力中位数为 0，流体 0.02 s 内以近自由落体下落穿过槽壁。

**改动**（`accumulate`，Crespo 等 2007 的动态边界，DualSPHysics 的默认做法）：固体粒子像流体一样对连续性方程做时间积分，不重置，下限 ρ₀：

```glsl
if (self_is_solid && SOLID_PRESSURE_MODE == 3u && SOLID_DENSITY_FLOOR) {
    new_density = max(new_density, self_params.rest_density);
}
```

`extrapolate`（Adami 等 2012）也实现了，静止方箱里密度持续下降，未采用。成对镜像（`mirror`）五个测试只过了 Couette，未采用。

**反作用受力**（`solid_reaction_force`）：固体粒子的加速度取"其流体邻居所受力的反作用"，a_j = −Σ_i (m_i/m_j) a_(i←j) + g，用流体粒子的矩阵、密度和压力算，
读回的固体受力恰为流体所受力的负值。静水浮力测试：壁面 −20.66 N 加方块 +0.39 N，合计 −20.27 N，流体重量 −20.27 N。

**影响**：静止方箱 0.3 s 压力稳定、无越壁；搅拌槽 1 g 下壁面竖直力等于流体重量（353.0 对 353.2 N）。`accumulate` 有约 0.3 dx 的贴壁间隙（动态边界的已知特征）。
密度下限 ρ₀ 在开重力时出问题，见第 4 节。

**需确认**：`accumulate` 是否可以作为有重力或背景压力算例的标准壁面；密度下限当初为什么加。

### 3.6 静水压初始密度

`physics.hydrostatic_reference` 给出静水压为零的点（顶盖）。流体粒子的初始密度按 Tait 流体的精确静水压剖面：

```python
# dp/dd = rho(p) g, p = B((rho/rho0)^gamma - 1)  =>  rho = rho0 (1 + (gamma-1)/gamma * rho0 g d / B)^(1/(gamma-1))
gamma = float(case.physics.power)
ratio = np.maximum(1.0 + (gamma - 1.0) / gamma * hydrostatic / float(material.eos_constant), 0.5)
density_pressure[cursor:cursor + n, 0] = material.rest_density * ratio ** (1.0 / (gamma - 1.0))
```

第一版按 p = ρ₀gd 积分，梯度比 ρg 小 ρ/ρ₀ − 1（槽底 1%）。`accumulate` 模式下壁面和转子粒子也按静水压初始化，
否则它们从 ρ₀、压力 0 起步，第 0 步槽底流体被吸向壁面（−335 m/s²）。只在设了参考点时起作用。

### 3.7 流体之间成对力的修正：`reverse`

**原来的代码**（`own`）：压力项和粘性项都用粒子 i 自己的矩阵，(P_i + P_j) B_i ∇W_ij。两个粒子看到的力不相等不相反。

**发现**：角动量收支（工具 `_check_blade_leak_tracking.py --budget`，Couette 上验证过）表明这一项凭空吃掉转子输入的角动量：
0.3 g 时 37%，1 g 时 92%。压力越高吃得越多，这就是"压力水平越高流动越慢"的原因，也是早期 PBT 与 Fluent 巧合接近的原因之一。

**改动**（Zhang、Adams、Hu 2025 的反向修正；`mean` 也实现了，两者差别在采样波动内）：

```glsl
// reverse correction: P_i B_j + P_j B_i; the TIC form keeps B_i
pressure_gradient_pair = symmetric_form
    ? (self_pressure * kernel_gradient_neighbor + neighbor_pressure * kernel_gradient_corrected)
    : (pressure_combined * kernel_gradient_corrected);
```

拆开看：(P_i B_j + P_j B_i)∇W = P_i(B_i + B_j)∇W + (P_j − P_i)B_i∇W，第二部分是粒子 i 的一阶精确梯度，第一部分与绝对压力成正比，是要靠粒子排列消除的残差。
粘性项用 ½(B_i + B_j) 和体积 2m/(ρ_i + ρ_j)。

**影响**：成对力项降到转子输入的 0.1% 到 0.4%，角动量交给壁面和挡板（1 g 时壁面拿走的从 2.7 变为 55.6）。二维 Couette 稳态误差从 −0.23% 到 −0.005%。
Rushton 1 g 时 40.9 → 45.2，PBT 19.3 → 20.5。

**需确认**：默认仍是 `own`；是否同意有重力或背景压力的算例改用 `reverse`；他对残差项的看法。

### 3.8 薄板的分侧镜像法（叶片、Rushton 圆盘、挡板）

**问题**：单层普通固体粒子被两侧流体同时看见，一侧的压力漏到另一侧。旋转桨叶的附加惯量测试：单层只给出理论值（ρπa⁴/8）的一半左右；
两侧静压差测试：单层保不住压差（−43 Pa）。

**方法**（读了 11 篇文献后选的体积形式，`shaders/thin_plates.glsl`，独立构建 `*_plates`）：板是解析的矩形或圆环，中面放一层粒子作标记。
对流体粒子 i，板背后的每个邻居（板粒子，或与 i 的连线穿过板的粒子）都当作壁面假想粒子：速度取板速，压力由 i 外推：

```glsl
if (!over_plate) {
    // beside the plate: the field of this side continued into the shadow
    return fluid_pressure + dot(fluid_pressure_gradient, offset);
}
// Over the plate. Along the wall: the gradient of the fluid. Normal to it: dp/dn = rho (g - a_w) . n
float mirror = fluid_pressure
             + dot(fluid_pressure_gradient, offset - offset_normal * plate_normal)
             + fluid_density * dot(relative_body_force, plate_normal) * offset_normal;
```

即 P_j = P_i + G_i·d_t + ρ_i[(g − a_w)·n](n·d)，a_w = α×r − ω²r_⊥ 含斜坡角加速度，G_i 是 `correction_plates` 里算的单侧密度梯度。
假想邻居不参与密度扩散、标量通量和成对力修正；修正矩阵、核函数和、PST 看见全部粒子。板的受力 = 流体所受力的反作用，逐粒子记录，收支残差 0.02% 到 0.1%。

**验证**：静压差 510 到 583 Pa 保持，受力比 0.98 到 0.99，无穿越；自由边稳定无漏；附加惯量 1.02 到 1.05（单层 0.91 或更低）；旋转桨叶无穿越。

**已知问题**：紧贴薄板的流体扰动是无板时的 2 到 3 倍（怀疑假想邻居不参与密度扩散，待试）；旋转桨叶力矩 4/2/1 mm 为 0.63/0.78/0.91，未收敛；
薄板构建慢 21% 到 27%（四种优化都无效）；RTX 5090 上未取分支的 NaN 会泄漏，全部表达式已改成有限值形式。

**需确认**：方法本身；旋转桨叶力矩不收敛的解释；2 mm 时薄板与单层相差 23%，哪个更可信。

### 3.9 PST 位移的输运项（试验，三种模式都不能用于正式算例）

**原来的代码**：x_{n+1} = x_n + v dt + δx_n，位移只改位置。合作者在 `density.comp` 注释了 "the shift moves particles without a term in the continuity equation"，
标量输运里加了 δx·∇C，密度和速度没有。

**后果**：角动量每步流失转子输入的 2% 到 6%（收支里的"位移项"）；粒子数密度可以与 SPH 密度分离（第 4 节的事故）。

**试验**（spec 76，默认 none）：密度项 ρ_i += −ρ_i Σ V_j(δx_j − δx_i)·∇W̃，动量项先试对流形式 Σ V_j(v_j − v_i)(δx_ij·∇W̃)，再试成对形式 F_ij = V_iV_j(ρ_iv_i + ρ_jv_j)(δx_ij·∇W_ij)。

| 4 mm，0 g，p_b 2000 | Rushton | 转子输入 | 流体间项 |
| --- | --- | --- | --- |
| 不带 | 44.2 | 83.4 | −0.15 |
| 动量对流形式（3 mm 6 s） | 34.2（原 43.1） | 70.3 | −20.6 |
| 动量成对形式 | 32.2 | 59.2 | +22.1 |
| 只开密度项 | 33.4 | 69.4 | −0.07 |

对流形式不是反作用力对，吃掉 25% 角动量；成对形式线动量守恒但力不沿连线，角动量反向多 25%；位移折合输运速度 4.6 cm/s，是流速的 5% 到 10%，这一项本来不小。
只开密度项时收支闭合，但 Rushton 从 44 掉到 33：PST 在固体表面有系统的法向分量（贴壁间隙），原来密度被钉住、间隙不影响压力，密度项把间隙如实记成膨胀，叶片表面压力下降。
三个缺陷被拆开：位移不带动量、位移不进密度、位移在固体表面有法向分量；修的顺序应是法向位移 → 密度项 → 沿连线的守恒动量项。

**需确认**：他是否知道这三点；文献里的一致形式（Sun 等 2019）在他的框架里怎么放。

## 4. 一次事故的诊断：2 mm 算例发散

**现象**：1 g、静水压初始的两个 2 mm 算例（单层、薄板）分别在 3.15 s 和 4.03 s 发散：最小密度几千步内从 997 掉到 900 以下，粒子丢失。3 mm 同设置 6 s 正常，30 s 也正常。

**定位**（在并行科技上重算到发散，每 500 步记录最小密度粒子的位置）：起点在顶盖下 1 到 3 层、离轴 100 到 135 mm 的一圈，与转子、窄缝、挡板无关。
发散前那里的粒子数只有格子的 30% 到 50%，而 SPH 密度仍是 998：粒子走掉一半，密度方程不知道。

**机理**：开重力时每一层都有向下的平均速度（顶盖下约 15 mm/s），PST 位移每步等量抬回。位置不变（位移抵消）、密度不变（压缩被扩散抹平）、粘性看不见均匀速度，
三条反馈都断了，下沉速度成为稳态，代价是顶层粒子稀疏（3 mm 6 s：槽底 104%，顶盖下 85%）。转子静止时一样；ξ、启动斜坡、PST 系数、初始剖面都不改变它。

**根源**：`accumulate` 的密度下限 ρ₀。静水压零点在顶盖，顶盖粒子要托住下面两层流体必须能取静水压的负延拓，下限把它钉成 0，顶盖下两层的支撑第 0 步就差 12%。
去掉下限（`solid_density_floor: false`）后下沉速度从 −0.39 降到 −0.02 × 10⁻³ dx/步，顶层粒子数稳定。副作用：壁面粒子随贴壁间隙形成而降密度，把全场密度带低 0.3% 到 0.6%，要配 p_b ≥ 3 kPa。

**采用的方案**：正式算例不开重力，用 p_b = 2000 Pa 抬压力水平。2 mm 两个算例算完 6 s，粒子数正常。重力是 9 月 29 日为抬高压力水平才开的，封闭单相槽里它只加静水压。

**需确认**：他是否见过这类现象；密度下限的来历；开重力的封闭槽应怎样处理顶盖。
